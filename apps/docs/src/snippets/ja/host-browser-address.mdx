{/* The host's steps both browser guides share: turning on browser access and copying the local address. */}

{productName} で <strong>設定 › アクセス</strong> を開きます。<strong>ブラウザアクセスを許可</strong>をオンにして、<strong>許可</strong>を選んで確定します。<strong>このコンピューターのブラウザ</strong>の下で、<strong>ローカルのアドレスをコピー</strong>を選びます。あわせて、<strong>ブラウザ用ポート</strong>の下に表示されている番号を控えておきます。

アドレスは、自分だけが読める方法でもう一方のコンピューターに渡してください。たとえば自分宛てのメモに貼り付けます。アドレスはパスワードと同じ働きをします。

<strong>手順 1: SSH フォワード</strong>は飛ばします。アプリの設定には SSH の話が何か所か出てきますが、このガイドで使うのはブラウザのアドレスだけなので、気にしなくて大丈夫です。

{productName} は起動したままにしてください。終了すると、ブラウザアクセスも止まります。
