{productName} で <strong>設定 › リモートアクセス</strong> を開き、<strong>リモートアクセスを許可</strong>をオンにして、<strong>許可</strong>を選んで確定します。スイッチの下に 2 つのタブが現れます。<strong>ブラウザ</strong>タブの <strong>手順 2: ブラウザのアドレス</strong> で、<strong>アドレスをコピー</strong>を選びます。{props.windows ? <>あわせて、<strong>ブラウザ用ポート</strong>の下に表示されている番号を控えておきます。</> : null}

アドレスは、自分だけが読める方法でもう一方のコンピューターに渡してください。たとえば自分宛てのメモに貼り付けます。アドレスはパスワードと同じ働きをします。

<strong>手順 1: SSH フォワード</strong>は飛ばします。アプリの設定には SSH の話が何か所か出てきますが、このガイドで使うのはブラウザのアドレスだけなので、気にしなくて大丈夫です。

{productName} は起動したままにしてください。終了すると、リモートアクセスも止まります。
