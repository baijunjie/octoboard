{/* What the Windows uninstaller does before it removes the app, which the Windows guide and "Your system stays as it was" share. */}

アンインストーラーは、何かを削除する前に自分でクリーンアップを行います。{productName} が動いていれば終了し（サイレントアンインストール以外では先に確認します）、<strong>すべて削除</strong>が削除するものをすべて、確認なしで削除します。その結果にかかわらず、続けてアンインストールします。削除できなかったものがあれば、最後に各項目がどこに残っているかとともに知らせ、<code dir="ltr">{system.uninstallLogWindows}</code> に一覧を書き出します。サイレントアンインストールでは、このファイルを書き出すだけです。

インストーラーとアンインストーラーは、{productName} がシステムの言語に対応していればその言語で、そうでなければ英語で表示されます。アンインストーラーと、残ったものの一覧は、インストールしたときの言語のままです。残った項目について機能が示す理由は、英語のことがあります。

すべてのアンインストールでこのクリーンアップが行われるわけではありません。アプリ内アップデートや、インストール済みのアプリの上から実行したセットアップでは行われず、リモートサーバー上の鍵やアカウントの共有はそのまま残ります。ただし、自分で上から実行したセットアップでは<strong>ログイン時に開く</strong>がオフになり、オンに戻すまでそのままです。このクリーンアップより前のバージョンのアンインストーラーも、クリーンアップを行いません。そうしたバージョンでは、先に<strong>すべて削除</strong>を選んでください。

<Aside>Windows on Arm 上の x64 版アプリでは、アンインストーラーは動いている {productName} を終了できず、何も削除しないままアンインストールが止まります。上から実行したセットアップも同じです。先に {productName} を終了してください。arm64 版アプリにはこの制限はなく、Arm PC 上の x64 版のインストールは、アプリ内アップデートで arm64 版に移ります。</Aside>
