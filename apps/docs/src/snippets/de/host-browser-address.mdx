{/* The host's steps both browser guides share: turning on browser access and copying the local address. */}

Öffne in {productName} <strong>Einstellungen › Zugriff</strong>. Schalte <strong>Browserzugriff erlauben</strong> ein und bestätige mit <strong>Erlauben</strong>. Wähle unter <strong>Browser auf diesem Computer</strong> die Option <strong>Lokale Adresse kopieren</strong>. Notiere dir außerdem die Zahl unter <strong>Browser-Port</strong>.

Bring die Adresse so zum anderen Computer, dass nur du sie lesen kannst, zum Beispiel als Notiz an dich selbst: Sie funktioniert wie ein Passwort.

Überspringe <strong>Schritt 1: SSH-Weiterleitung</strong>. Die Einstellungen der App erwähnen SSH an mehreren Stellen; das kannst du hier ignorieren, denn diese Anleitung nutzt nur die Browser-Adresse.

Lass {productName} geöffnet: Wenn du es beendest, endet der Browserzugriff.
