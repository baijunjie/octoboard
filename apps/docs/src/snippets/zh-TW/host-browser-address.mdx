在 {productName} 中開啟<strong>設定 › 存取</strong>。開啟<strong>允許瀏覽器存取</strong>，再點選<strong>允許</strong>確認。在<strong>這台電腦的瀏覽器</strong>下，點選<strong>複製本機位址</strong>。同時記下<strong>瀏覽器連接埠</strong>下顯示的連接埠號碼。

請用只有你自己看得到的方式把位址傳到另一台電腦，例如傳給自己的筆記：它的作用就像密碼。

跳過<strong>步驟 1：SSH 轉送</strong>。應用程式的設定裡有多處提到 SSH，這裡可以不用理會，本指南只會用到瀏覽器位址。

請讓 {productName} 保持執行，結束後瀏覽器存取也會隨之中斷。
