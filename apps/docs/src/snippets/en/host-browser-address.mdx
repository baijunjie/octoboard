{/* The host's steps both browser guides share: turning on browser access and copying the local address. */}

In {productName}, open <strong>Settings › Access</strong>. Turn on <strong>Allow browser access</strong> and select <strong>Allow</strong> to confirm. Under <strong>This computer's browser</strong>, select <strong>Copy local address</strong>. Also note the number under <strong>Browser port</strong>.

Get the address to the other computer in a way only you can read, such as a note to yourself: it works like a password.

Skip <strong>Step 1: SSH forward</strong>. The app's settings mention SSH in several places; you can ignore that here, since this guide uses only the browser address.

Keep {productName} running: if you quit it, browser access stops.
