В {productName} откройте <strong>Настройки › Доступ</strong>. Включите <strong>Разрешить доступ из браузера</strong> и нажмите <strong>Разрешить</strong>, чтобы подтвердить. В разделе <strong>Браузер на этом компьютере</strong> нажмите <strong>Копировать локальный адрес</strong>. Запишите также число в поле <strong>Порт браузера</strong>.

Передайте адрес на другой компьютер так, чтобы его видели только вы, например заметкой для самого себя: он работает как пароль.

Пропустите <strong>Шаг 1: SSH-перенаправление</strong>. В настройках приложения SSH упоминается в нескольких местах; здесь это можно не учитывать, потому что в этой инструкции нужен только адрес для браузера.

Не закрывайте {productName}: если вы выйдете из приложения, доступ из браузера прекратится.
