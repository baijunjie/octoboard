{/* The host's steps both browser guides share: turning on browser access and copying the local address. */}

Dans {productName}, ouvrez <strong>Réglages › Accès</strong>. Activez <strong>Autoriser l’accès par navigateur</strong> et sélectionnez <strong>Autoriser</strong> pour confirmer. Sous <strong>Navigateur de cet ordinateur</strong>, sélectionnez <strong>Copier l’adresse locale</strong>. Notez aussi le nombre indiqué sous <strong>Port du navigateur</strong>.

Transmettez l’adresse à l’autre ordinateur d’une façon que vous seul pouvez lire, par exemple une note envoyée à vous-même : elle fonctionne comme un mot de passe.

Ignorez <strong>Étape 1 : redirection SSH</strong>. Les réglages de l’app mentionnent SSH à plusieurs endroits ; vous pouvez l’ignorer ici, puisque ce guide n’utilise que l’adresse du navigateur.

Laissez {productName} en marche : si vous le quittez, l’accès par navigateur s’arrête.
