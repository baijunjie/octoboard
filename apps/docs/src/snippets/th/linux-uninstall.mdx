{/* How the Linux server program is uninstalled, which the Linux server guide and "Your system stays as it was" share. */}

รันคำสั่งนี้บนเซิร์ฟเวอร์ในฐานะผู้ใช้ที่ติดตั้งไว้ โดยจะไม่มีการดาวน์โหลดอะไร

<Code code={system.uninstall} lang="sh" />

คำสั่งนี้จะแสดงรายการทุกอย่างที่จะทำก่อน แล้วขอให้คุณพิมพ์ <code dir="ltr">{system.uninstallWord}</code> ตัวเลือก <code dir="ltr">{system.uninstallDryRun}</code> จะแสดงเพียงรายการนั้น และ <code dir="ltr">{system.uninstallYes}</code> ใช้ยืนยันในกรณีที่ไม่มีเทอร์มินัลให้ถาม

จากนั้นจะปิดการใช้ร่วมกันของทุกบัญชีที่ยังใช้การกำหนดค่าเริ่มต้นร่วมกันอยู่ เพื่อการนี้ หากดีมอนทำงานอยู่ คำสั่งจะหยุดดีมอน ซึ่งจะจบทุกเซสชันที่ดีมอนรันอยู่ แล้วเริ่มดีมอนเฉพาะสำหรับการเก็บกวาดครั้งนี้โดยไม่รันเซสชันใด หลังจากนั้นจะหยุดดีมอน แล้วลบโปรแกรม พร้อมบริการ systemd ของโปรแกรมหากมี และปิด lingering หากการติดตั้งบริการเป็นผู้เปิดไว้และไม่มีบริการอื่นของคุณที่ต้องใช้

- <strong>หากบัญชีใดหยุดการใช้ร่วมกันไม่ได้</strong> เช่น เพราะมีเซสชันของบัญชีนั้นกำลังทำงานอยู่ จะไม่มีอะไรถูกลบ และดีมอนจะถูกเริ่มใหม่ตามที่เคยทำงาน ให้รันคำสั่งอีกครั้งเมื่องานนั้นเสร็จแล้ว หากใส่ <code dir="ltr">{system.uninstallKeepChanges}</code> คำสั่งจะถอนการติดตั้งโดยไม่เก็บกวาดส่วนนี้ และทิ้งลิงก์ในโฟลเดอร์ของแต่ละบัญชีดังกล่าว พร้อมข้อมูลสำรองของการกำหนดค่าของบัญชีนั้นเองที่อยู่ข้างกัน ไว้ให้คุณลบเอง
- <strong>หากการหยุดดีมอนจะขัดจังหวะงาน</strong> จะไม่มีอะไรถูกลบ ตัวเลือก <code dir="ltr">{system.uninstallForce}</code> จะหยุดดีมอนอยู่ดี
- <strong>ให้รัน <code dir="ltr">{system.cliName}</code> ตัวที่คุณติดตั้ง</strong> หากรันผ่านลิงก์ หรือรันจาก <code dir="ltr">{system.cliName}</code> สำเนาอื่นที่ไม่ใช่ตัวที่ดีมอนของ {productName} รันอยู่ คำสั่งจะไม่ลบอะไร และบอกชื่อไฟล์ที่ควรรันแทน

คำสั่งเดิมของสคริปต์ติดตั้งยังใช้ได้ และจะรันคำสั่งนี้ให้ หากคุณติดตั้งด้วย <code dir="ltr">{system.binDirOption}</code> ให้ใส่ตัวเลือกนี้พร้อมโฟลเดอร์เดิม

<Code code={system.uninstallScript} lang="sh" />

หาก <code dir="ltr">{system.cliName}</code> ของคุณเก่าเกินกว่าจะมีคำสั่งถอนการติดตั้ง คำสั่งของสคริปต์จะลบมันเอง แต่จะไม่ปิดอะไรก่อน บัญชีที่ยังใช้การกำหนดค่าเริ่มต้นร่วมกันอยู่จะยังมีลิงก์ในโฟลเดอร์ของตน ซึ่งคุณลบเองได้
