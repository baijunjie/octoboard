{/* What the Windows uninstaller does before it removes the app, which the Windows guide and "Your system stays as it was" share. */}

ก่อนลบสิ่งใด ตัวถอนการติดตั้งจะเก็บกวาดเอง โดยปิด {productName} หากกำลังทำงานอยู่ ซึ่งจะถามก่อน ยกเว้นการถอนการติดตั้งแบบเงียบ แล้วลบทุกอย่างที่ <strong>ลบทั้งหมด</strong> ลบโดยไม่ถาม จากนั้นจึงถอนการติดตั้งไม่ว่าผลจะเป็นอย่างไร หากมีสิ่งที่ลบไม่ได้ ตัวถอนการติดตั้งจะบอกในตอนท้ายพร้อมตำแหน่งที่แต่ละรายการยังค้างอยู่ และบันทึกรายการไว้ใน <code dir="ltr">{system.uninstallLogWindows}</code> ส่วนการถอนการติดตั้งแบบเงียบจะเขียนเพียงไฟล์นี้

ตัวติดตั้งและตัวถอนการติดตั้งจะใช้ภาษาของระบบคุณหาก {productName} มีภาษานั้น หากไม่มีจะใช้ภาษาอังกฤษ ตัวถอนการติดตั้งและรายการสิ่งที่ค้างอยู่จะใช้ภาษาเดียวกับตอนที่คุณติดตั้ง ส่วนเหตุผลที่ฟีเจอร์ให้ไว้สำหรับรายการที่ค้างอยู่อาจเป็นภาษาอังกฤษ

ไม่ใช่ทุกการถอนการติดตั้งที่จะเก็บกวาดส่วนนี้ การอัปเดตภายในแอปและตัวติดตั้งที่รันทับแอปที่ติดตั้งอยู่จะไม่ทำ คีย์ของคุณบนเซิร์ฟเวอร์ระยะไกลและการใช้ร่วมกันของบัญชีจึงยังคงเดิม แต่ตัวติดตั้งที่คุณรันทับเองยังคงปิด <strong>เปิดเมื่อเข้าสู่ระบบ</strong> จนกว่าคุณจะเปิดอีกครั้ง ตัวถอนการติดตั้งของเวอร์ชันก่อนที่จะมีการเก็บกวาดนี้ก็ไม่ทำเช่นกัน สำหรับเวอร์ชันแบบนั้น ให้เลือก <strong>ลบทั้งหมด</strong> ก่อน

<Aside>สำหรับแอป x64 บน Windows on Arm ตัวถอนการติดตั้งไม่สามารถปิด {productName} ที่กำลังทำงานอยู่ได้ และการถอนการติดตั้งจะหยุดโดยไม่ลบอะไร ตัวติดตั้งที่รันทับก็เช่นกัน ให้ออกจาก {productName} ก่อน แอป arm64 ไม่มีข้อจำกัดนี้ และการติดตั้ง x64 บนพีซี Arm จะย้ายไปใช้แอป arm64 ผ่านการอัปเดตภายในแอป</Aside>
