{/* The host's steps both browser guides share: turning on browser access and copying the local address. */}

In {productName} apri <strong>Impostazioni › Accesso</strong>. Attiva <strong>Consenti accesso dal browser</strong> e seleziona <strong>Consenti</strong> per confermare. Sotto <strong>Browser di questo computer</strong>, seleziona <strong>Copia indirizzo locale</strong>. Annota anche il numero sotto <strong>Porta del browser</strong>.

Fai arrivare l’indirizzo all’altro computer in un modo che solo tu puoi leggere, come una nota per te: funziona come una password.

Salta <strong>Passaggio 1: inoltro SSH</strong>. Le impostazioni dell’app citano SSH in più punti; qui puoi ignorarli, perché questa guida usa solo l’indirizzo del browser.

Tieni {productName} in esecuzione: se lo chiudi, l’accesso dal browser si interrompe.
