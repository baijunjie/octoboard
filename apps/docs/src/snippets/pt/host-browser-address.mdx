No {productName}, abra <strong>Ajustes › Acesso</strong>. Ative <strong>Permitir acesso pelo navegador</strong> e selecione <strong>Permitir</strong> para confirmar. Na seção <strong>Navegador deste computador</strong>, selecione <strong>Copiar endereço local</strong>. Anote também o número em <strong>Porta do navegador</strong>.

Leve o endereço ao outro computador de um jeito que só você possa ler, como uma nota para si mesmo: ele funciona como uma senha.

Ignore <strong>Etapa 1: encaminhamento SSH</strong>. As configurações do app mencionam o SSH em vários lugares; você pode ignorar isso aqui, pois este guia usa apenas o endereço do navegador.
