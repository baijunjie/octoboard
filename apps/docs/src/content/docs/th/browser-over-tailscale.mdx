เปิด {productName} ในเบราว์เซอร์บนคอมพิวเตอร์เครื่องอื่นผ่านเครือข่าย Tailscale ของคุณเอง โดยไม่ต้องใช้ SSH หรือรีโมตเดสก์ท็อป โฮสต์คือคอมพิวเตอร์ที่รัน {productName} ได้แก่ Mac, พีซี Windows หรือเซิร์ฟเวอร์ Linux ที่รัน octoboardd การลงชื่อเข้าใช้ด้วย SSH (Remote Login บน macOS) ปิดไว้ได้

ไม่แน่ใจว่าวิธีนี้เหมาะกับคุณหรือไม่ ดู [เลือกวิธีเชื่อมต่อ](../choose-how-to-connect/)

<Aside type="caution">
ขั้นตอนเหล่านี้ยังไม่ได้ทดสอบครบถ้วน ทำตามเอกสาร Tailscale Serve และการตรวจสอบของ {productName} เอง โปรแกรมตัวส่งต่อได้ลองบนคอมพิวเตอร์เครื่องเดียวแล้ว รวมถึงการเชื่อมต่อสดของเบราว์เซอร์ ส่วน Tailscale Serve ระหว่างสองอุปกรณ์และการส่งต่อบน Windows ยังไม่ได้ลอง
</Aside>

<details>
<summary>เพิ่งเริ่มใช้ใช่ไหม</summary>

- <strong>Tailscale:</strong> บริการที่เชื่อมอุปกรณ์ของคุณเข้าเป็นเครือข่ายส่วนตัวผ่านอินเทอร์เน็ต ไม่ว่าอุปกรณ์จะอยู่ที่ไหน คุณลงชื่อเข้าใช้ด้วยบัญชีของคุณเอง
- <strong>Tailnet:</strong> เครือข่าย Tailscale ของคุณ คืออุปกรณ์ที่ลงชื่อเข้าใช้บัญชี Tailscale ของคุณ
- <strong>127.0.0.1 (loopback):</strong> ที่อยู่ที่หมายถึง “คอมพิวเตอร์เครื่องเดียวกันนี้” เสมอ
- <strong>พอร์ต:</strong> ตัวเลขที่ใช้เลือกโปรแกรมหนึ่งบนคอมพิวเตอร์ เหมือนเลขประตู <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> คือพอร์ต {commands.defaultPort} บนคอมพิวเตอร์เครื่องนี้
- <strong>socat:</strong> โปรแกรมเล็ก ๆ ที่ใช้ฟรี ทำหน้าที่ส่งต่อการเชื่อมต่อจากที่หนึ่งไปอีกที่หนึ่ง ในที่นี้คือตัวส่งต่อ
- <strong>Tailscale Serve:</strong> คำสั่งของ Tailscale ที่แชร์พอร์ตให้เฉพาะ tailnet ของคุณ ส่วน Tailscale Funnel ซึ่งเป็นคำสั่งคู่กันจะแชร์ให้ทั้งอินเทอร์เน็ต อย่าใช้ในที่นี้เด็ดขาด
- <strong>Terminal:</strong> หน้าต่างที่ใช้พิมพ์คำสั่ง คือ Terminal บน macOS และ PowerShell บน Windows

</details>

## ทำไมต้องมีขั้นตอนเพิ่ม

เพื่อความปลอดภัย {productName} ยอมรับเฉพาะเบราว์เซอร์ที่เปิดมันที่ <code dir="ltr">{tunnel.loopback}</code> ซึ่งเป็นที่อยู่ที่หมายถึง “คอมพิวเตอร์เครื่องเดียวกันนี้” เสมอ (เรียกอีกอย่างว่า loopback) คุณจึงพิมพ์ที่อยู่ Tailscale ของโฮสต์ลงในเบราว์เซอร์ตรง ๆ ไม่ได้ แต่ให้รันโปรแกรมตัวส่งต่อเล็ก ๆ บนคอมพิวเตอร์แต่ละเครื่อง บนคอมพิวเตอร์ของคุณ มันทำให้โฮสต์ดูเหมือนอยู่ในเครื่องที่ <code dir="ltr">{tunnel.loopback}</code> บนโฮสต์ มันส่งต่อการเชื่อมต่อให้ {productName} ส่วน Tailscale พาข้อมูลระหว่างสองฝั่ง

## หากใช้งานไม่ได้

- <strong>หน้าเว็บไม่โหลด:</strong> หน้าต่างใดหน้าต่างหนึ่งถูกปิด หรือคำสั่งหยุดทำงาน ตรวจสอบว่าตัวส่งต่อและ Tailscale Serve ยังทำงานอยู่ และ <code dir="ltr">{tunnel.serveStatus}</code> บนโฮสต์แสดงพอร์ตของโฮสต์
- <strong>socat แจ้ง “Address already in use”:</strong> พอร์ตนั้นถูกใช้อยู่แล้วบนเครื่องนั้น ให้เลือกพอร์ตอื่น บนคอมพิวเตอร์ของคุณให้เปลี่ยนในที่อยู่ของเบราว์เซอร์ด้วย
- <strong>หน้าเว็บถูกปฏิเสธหรือว่างเปล่า:</strong> ตรวจสอบว่าคุณเปิดที่อยู่ที่ <code dir="ltr">{tunnel.loopback}</code> ไม่ใช่ชื่อ Tailscale ของโฮสต์หรือที่อยู่ <code dir="ltr">100.x.y.z</code>
- <strong>ตัวส่งต่อบนโฮสต์แสดง “Connection refused” หรือ “No such file or directory” เมื่อคุณเปิดหน้าเว็บ:</strong> <strong>อนุญาตการเข้าถึงระยะไกล</strong> ปิดอยู่ หรือ {productName} ไม่ได้ทำงานบนโฮสต์ (บน Linux คือ octoboardd ไม่ได้ทำงาน)

## ปิดการใช้งาน

- <strong>บนคอมพิวเตอร์ที่คุณใช้เปิดเบราว์เซอร์:</strong> หยุด socat ด้วย <kbd>Ctrl</kbd>+<kbd>C</kbd> หรือบน Windows ให้ลบการส่งต่อใน PowerShell ที่รันแบบผู้ดูแลระบบ

  <Code code={tunnel.visitorForwardWindowsOff} lang="powershell" />
- <strong>บนโฮสต์:</strong> หยุดคำสั่ง Tailscale Serve และ socat ด้วย <kbd>Ctrl</kbd>+<kbd>C</kbd> ตรวจสอบด้วย <code dir="ltr">{tunnel.serveStatus}</code> ว่าไม่มีอะไรถูกแชร์อยู่อีก หากพอร์ตยังอยู่ในรายการ ให้ลบด้วย <code dir="ltr">{tunnel.serveBridgeOff}</code> (บน Windows คือ <code dir="ltr">{tunnel.serveBrowserPortOff}</code>)
- <strong>บนโฮสต์ Mac หรือ Windows</strong> ให้ปิด <strong>อนุญาตการเข้าถึงระยะไกล</strong> เมื่อไม่ต้องใช้อีก เป็นการปิดทางเข้าของเบราว์เซอร์และตัดการเชื่อมต่อของทุกหน้าที่เปิดด้วยคีย์นั้น
- <strong>หากที่อยู่อาจรั่วไหล</strong> ให้สร้างคีย์ใหม่ด้วย <strong>เปลี่ยนคีย์</strong> ที่แท็บ <strong>เบราว์เซอร์</strong> หรือบน Linux ด้วย <code dir="ltr">{tunnel.rotate}</code> หน้าที่เปิดด้วยที่อยู่เก่าจะถูกตัดการเชื่อมต่อ

## ความปลอดภัย

- <strong>ที่อยู่นี้คือรหัสผ่าน:</strong> คีย์ของมันควบคุม {productName} บนโฮสต์ได้เต็มรูปแบบ รวมถึงการรันคำสั่งใดก็ได้ และคีย์ใช้ได้จนกว่าคุณจะเปลี่ยน มันอยู่ในประวัติและบุ๊กมาร์กของเบราว์เซอร์ และซิงก์ไปยังอุปกรณ์อื่นของคุณหากเปิดการซิงก์ของเบราว์เซอร์
- <strong>ใครเข้าถึงได้:</strong> ทุกคนที่เข้าถึงพอร์ตของโฮสต์ได้และมีคีย์ ตัวส่งต่อรับฟังที่ <code dir="ltr">127.0.0.1</code> เท่านั้น อุปกรณ์อื่นในเครือข่ายของโฮสต์หรือเครือข่ายในบ้านของคุณจึงเข้าถึงไม่ได้ Tailscale Serve ทำให้พอร์ตของโฮสต์เข้าถึงได้จาก tailnet ของคุณเท่านั้น ตามที่กฎการเข้าถึงของมันอนุญาต
- <strong>ใช้เฉพาะบนคอมพิวเตอร์ที่ไม่มีคนอื่นลงชื่อเข้าใช้:</strong> บัญชีผู้ใช้อื่นบนโฮสต์หรือบนคอมพิวเตอร์ของคุณเชื่อมต่อกับพอร์ต <code dir="ltr">127.0.0.1</code> เหล่านี้ได้ และขณะที่ตัวส่งต่อไม่ได้ทำงาน บัญชีนั้นอาจยึดพอร์ตของมันและรับคีย์เมื่อเบราว์เซอร์ของคุณเชื่อมต่อใหม่ [การเชื่อมต่อผ่าน SSH](../remote-connections/) ไม่มีจุดอ่อนนี้บนโฮสต์ Mac หรือ Linux และคอมพิวเตอร์ของคุณเองก็ไม่มีเมื่อใช้แอปบนเดสก์ท็อป แต่ในเบราว์เซอร์ คอมพิวเตอร์ของคุณยังมีจุดอ่อนนี้อยู่ เพราะการส่งต่อพอร์ตของ SSH ตรงนั้นก็รอรับการเชื่อมต่อที่พอร์ต <code dir="ltr">127.0.0.1</code> เช่นกัน
- <strong>ห้ามใช้ Funnel เด็ดขาด:</strong> Tailscale Funnel จะเผยแพร่พอร์ตสู่ทั้งอินเทอร์เน็ต
