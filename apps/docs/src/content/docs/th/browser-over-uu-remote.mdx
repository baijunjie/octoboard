เปิด {productName} ในเบราว์เซอร์บนคอมพิวเตอร์เครื่องอื่นผ่านการแมปพอร์ตของ [UU Remote](https://uuyc.163.com/) แอปควบคุมระยะไกลของ NetEase โดยไม่ต้องใช้ SSH หรือรีโมตเดสก์ท็อป โฮสต์คือคอมพิวเตอร์ที่รัน {productName} การลงชื่อเข้าใช้ด้วย SSH (Remote Login บน macOS) ปิดไว้ได้ และไม่ต้องมีเซสชันรีโมตเดสก์ท็อป หน้าจอของ UU Remote เป็นภาษาจีน คู่มือนี้จึงให้ป้ายชื่อภาษาจีนของมันไว้ข้างภาษาอังกฤษ

คู่มือนี้เปิด {productName} ในเบราว์เซอร์บนคอมพิวเตอร์ของคุณเอง วิธีนี้คมชัดและตอบสนองเร็วกว่ารีโมตเดสก์ท็อป แต่มีขั้นตอนมากกว่า ถ้าไม่ถือสาความหน่วงกับภาพที่เบลอ ก็ใช้รีโมตเดสก์ท็อปของ UU Remote เพื่อทำงานบนโฮสต์โดยตรงได้เลย

ไม่แน่ใจว่าวิธีนี้เหมาะกับคุณหรือไม่ ดู [เลือกวิธีเชื่อมต่อ](../choose-how-to-connect/)

<Aside type="caution">
ขั้นตอนเหล่านี้ยังไม่ได้ทดสอบระหว่างสองอุปกรณ์ ทำตามวิธีใช้ของ UU Remote เอง ตัวส่งต่อบนโฮสต์ Mac ได้ลองบนคอมพิวเตอร์เครื่องเดียวแล้ว รวมถึงการเชื่อมต่อสดของเบราว์เซอร์
</Aside>

<details>
<summary>เพิ่งเริ่มใช้ใช่ไหม</summary>

- <strong>127.0.0.1 (loopback):</strong> ที่อยู่ที่หมายถึง “คอมพิวเตอร์เครื่องเดียวกันนี้” เสมอ
- <strong>พอร์ต:</strong> ตัวเลขที่ใช้เลือกโปรแกรมหนึ่งบนคอมพิวเตอร์ เหมือนเลขประตู <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> คือพอร์ต {commands.defaultPort} บนคอมพิวเตอร์เครื่องนี้
- <strong>การแมปพอร์ต (端口映射):</strong> ฟีเจอร์ของ UU Remote ที่ทำให้พอร์ตบนโฮสต์ปรากฏเป็นพอร์ตบนคอมพิวเตอร์ของคุณเอง
- <strong>socat:</strong> โปรแกรมเล็ก ๆ ที่ใช้ฟรี ทำหน้าที่ส่งต่อการเชื่อมต่อจากที่หนึ่งไปอีกที่หนึ่ง โฮสต์ Mac ต้องใช้เป็นตัวส่งต่อ
- <strong>Terminal:</strong> หน้าต่างที่ใช้พิมพ์คำสั่ง คือ Terminal บน macOS และ PowerShell บน Windows

</details>

การแมปพอร์ตของ UU Remote ทำให้ {productName} ของโฮสต์ปรากฏบนคอมพิวเตอร์ของคุณเองที่ <code dir="ltr">{tunnel.loopback}</code> ซึ่งเป็นที่อยู่เดียวที่ {productName} ยอมรับเบราว์เซอร์

## ก่อนเริ่ม

- <strong>คอมพิวเตอร์ทั้งสองเครื่องเป็น Mac หรือพีซี Windows</strong> UU Remote ไม่มีการแมปพอร์ตสำหรับ Linux หากต้องการเข้าถึงเซิร์ฟเวอร์ Linux ให้ใช้ [Tailscale](../browser-over-tailscale/) หรือ [SSH](../remote-connections/) แทน
- <strong>ทั้งสองเครื่องติดตั้ง UU Remote และลงชื่อเข้าใช้บัญชีเดียวกัน</strong> เวอร์ชัน 4.21.0 ขึ้นไปบน Windows และ 4.32.0 ขึ้นไปบน macOS การแมปพอร์ตใช้ได้กับ TCP เท่านั้น ซึ่งเป็นสิ่งเดียวที่ {productName} ต้องการ ณ เวลาที่เขียน UU Remote จัดการแมปพอร์ตไว้ในฟีเจอร์ฟรี หากไม่แน่ใจ ให้ตรวจสอบแพ็กเกจปัจจุบันของมัน
- <strong>โฮสต์ปรากฏใน อุปกรณ์ของฉัน (我的设备)</strong> ใน UU Remote บนคอมพิวเตอร์ที่คุณจะใช้เปิดเบราว์เซอร์
- <strong>โฮสต์ Mac ต้องมี [Homebrew](https://brew.sh/) ด้วย</strong> เพื่อติดตั้ง socat ด้านล่าง

## บนคอมพิวเตอร์ที่คุณจะใช้เปิดเบราว์เซอร์

<Steps>

1. ใน UU Remote ให้เปิดโฮสต์จาก <strong>อุปกรณ์ของฉัน</strong> (我的设备) เลือก <strong>เพิ่มเติม</strong> (更多) บนการ์ดของมัน แล้วเลือก <strong>การแมปพอร์ต</strong> (端口映射) และเพิ่มการแมป

   | ช่อง | ค่า |
   | --- | --- |
   | ชื่อ (名称) | {productName} |
   | พอร์ตในเครื่อง (本地端口) | <code dir="ltr">{commands.defaultPort}</code> |
   | ที่อยู่เป้าหมาย (目标地址) | <code dir="ltr">127.0.0.1</code> |
   | พอร์ตเป้าหมาย (目标端口) | พอร์ตของโฮสต์ |

   บันทึกและเปิดใช้งาน แล้วรอจนแสดงว่าเชื่อมต่อแล้ว หากพอร์ต {commands.defaultPort} ถูกใช้อยู่แล้วบนคอมพิวเตอร์เครื่องนี้ ให้เลือกพอร์ตในเครื่องอื่นและเปลี่ยนในที่อยู่ของเบราว์เซอร์ด้วย
2. ตรวจสอบว่ามีเพียงคอมพิวเตอร์เครื่องนี้เท่านั้นที่ใช้การแมปได้ เปิด Terminal (macOS) หรือ PowerShell (Windows) บนคอมพิวเตอร์เครื่องนี้ แล้วรัน

   คุณควรเห็นบรรทัดที่มี <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> และ <code dir="ltr">LISTEN</code>
   </TabItem>
   <TabItem label="Windows">
   <Code code={tunnel.checkListenerWindows} lang="powershell" />

   คุณควรเห็นบรรทัดที่ขึ้นต้นด้วย <code dir="ltr">TCP</code> ตามด้วย <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> และลงท้ายด้วย <code dir="ltr">LISTENING</code> และตัวเลข
   </TabItem>
   </Tabs>

   หากคุณเห็น <code dir="ltr">*:{commands.defaultPort}</code> หรือ <code dir="ltr">0.0.0.0:{commands.defaultPort}</code> แทน ให้ลบการแมปนั้น เพราะอุปกรณ์อื่นในเครือข่ายของคุณอาจเข้าถึง {productName} ได้
3. เปิดที่อยู่ของเบราว์เซอร์ที่คุณคัดลอกบนโฮสต์ ซึ่งขึ้นต้นด้วย <code dir="ltr">{tunnel.addressStart}</code>

คุณจะรู้ว่าสำเร็จเมื่อ {productName} เปิดขึ้นในแท็บของเบราว์เซอร์โดยไม่ให้คุณลงชื่อเข้าใช้

## หากใช้งานไม่ได้

- <strong>การแมปแสดงว่าเชื่อมต่อแล้ว แต่หน้าเว็บไม่โหลด:</strong> บนโฮสต์ Mac หน้าต่าง socat ถูกปิดหรือคำสั่งหยุดทำงาน หรือ <strong>อนุญาตการเข้าถึงระยะไกล</strong> ปิดอยู่ หรือ {productName} ไม่ได้ทำงานบนโฮสต์
- <strong>การแมปบันทึกหรือเชื่อมต่อไม่ได้:</strong> พอร์ตในเครื่องอาจถูกใช้อยู่แล้วบนคอมพิวเตอร์เครื่องนี้ ให้เลือกพอร์ตอื่น และเปลี่ยนในที่อยู่ของเบราว์เซอร์ด้วย
- <strong>หน้าเว็บถูกปฏิเสธหรือว่างเปล่า:</strong> ตรวจสอบว่าคุณเปิดที่อยู่ที่ <code dir="ltr">{tunnel.loopback}</code>

## ปิดการใช้งาน

- <strong>บนคอมพิวเตอร์ที่คุณใช้เปิดเบราว์เซอร์:</strong> ปิดการแมปในแผงการแมปพอร์ตของ UU Remote หรือลบทิ้ง การปิดแผงหรือตัดการเชื่อมต่อก็หยุดการแมปเช่นกัน
- <strong>บนโฮสต์ Mac:</strong> หยุด socat ด้วย <kbd>Ctrl</kbd>+<kbd>C</kbd>
- <strong>บนโฮสต์</strong> ให้ปิด <strong>อนุญาตการเข้าถึงระยะไกล</strong> เมื่อไม่ต้องใช้อีก เป็นการปิดทางเข้าของเบราว์เซอร์และตัดการเชื่อมต่อของทุกหน้าที่เปิดด้วยคีย์นั้น
- <strong>หากที่อยู่อาจรั่วไหล</strong> ให้สร้างคีย์ใหม่ด้วย <strong>เปลี่ยนคีย์</strong> ที่แท็บ <strong>เบราว์เซอร์</strong> หน้าที่เปิดด้วยที่อยู่เก่าจะถูกตัดการเชื่อมต่อ

## ความปลอดภัย

- <strong>ที่อยู่นี้คือรหัสผ่าน:</strong> คีย์ของมันควบคุม {productName} บนโฮสต์ได้เต็มรูปแบบ รวมถึงการรันคำสั่งใดก็ได้ และคีย์ใช้ได้จนกว่าคุณจะเปลี่ยน มันอยู่ในประวัติและบุ๊กมาร์กของเบราว์เซอร์ และซิงก์ไปยังอุปกรณ์อื่นของคุณหากเปิดการซิงก์ของเบราว์เซอร์
- <strong>ใครเข้าถึงได้:</strong> ทุกคนที่เข้าถึงพอร์ตของโฮสต์ได้และมีคีย์ บนโฮสต์ มันรับฟังที่ <code dir="ltr">127.0.0.1</code> เท่านั้น ผู้ที่ใช้บัญชี UU Remote ของคุณแมปพอร์ตไปยังโฮสต์ได้ก็เข้าถึงได้เช่นกัน ดังนั้นโปรดรักษาความปลอดภัยของบัญชีนั้น
- <strong>ใช้เฉพาะบนคอมพิวเตอร์ที่ไม่มีคนอื่นลงชื่อเข้าใช้:</strong> บัญชีผู้ใช้อื่นบนโฮสต์หรือบนคอมพิวเตอร์ของคุณเชื่อมต่อกับพอร์ต <code dir="ltr">127.0.0.1</code> เหล่านี้ได้ และขณะที่การแมปหรือ socat ไม่ได้ทำงาน บัญชีนั้นอาจยึดพอร์ตและรับคีย์เมื่อเบราว์เซอร์ของคุณเชื่อมต่อใหม่ [การเชื่อมต่อผ่าน SSH](../remote-connections/) ไม่มีจุดอ่อนนี้บนโฮสต์ Mac หรือ Linux และคอมพิวเตอร์ของคุณเองก็ไม่มีเมื่อใช้แอปบนเดสก์ท็อป แต่ในเบราว์เซอร์ คอมพิวเตอร์ของคุณยังมีจุดอ่อนนี้อยู่ เพราะการส่งต่อพอร์ตของ SSH ตรงนั้นก็รอรับการเชื่อมต่อที่พอร์ต <code dir="ltr">127.0.0.1</code> เช่นกัน
