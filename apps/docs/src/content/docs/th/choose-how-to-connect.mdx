</Aside>

## ก่อนเลือกตัวส่งต่อ

คู่มือตัวส่งต่อมีขั้นตอนมากกว่า SSH คุณต้องรันคำสั่งบนคอมพิวเตอร์ทั้งสองเครื่อง และเปิดหน้าต่างค้างไว้ตลอดขณะทำงาน

<Aside type="caution">
คู่มือ Tailscale และ UU Remote ยังไม่ได้ทดสอบครบถ้วนระหว่างสองอุปกรณ์ คู่มือเหล่านี้ทำตามเอกสารของบริการนั้น ๆ และการตรวจสอบของ {productName} เอง
</Aside>

<Aside type="caution" title="ใช้เฉพาะบนคอมพิวเตอร์ที่ไม่มีคนอื่นลงชื่อเข้าใช้">
เมื่อใช้ตัวส่งต่อ บัญชีผู้ใช้อื่นบนโฮสต์หรือบนคอมพิวเตอร์ของคุณอาจดักเอาคีย์ของเบราว์เซอร์ไปได้ ให้ใช้ Tailscale หรือ UU Remote เฉพาะบนคอมพิวเตอร์ที่มีแต่คุณคนเดียวลงชื่อเข้าใช้ [การเชื่อมต่อผ่าน SSH](../remote-connections/) ไม่มีจุดอ่อนนี้บนโฮสต์ Linux ที่ปิดการเข้าถึงจากเบราว์เซอร์ และบนโฮสต์ Mac หรือ Windows เมื่อใช้แอปบนเดสก์ท็อป และคอมพิวเตอร์ของคุณเองก็ไม่มีเมื่อใช้แอปบนเดสก์ท็อป แต่ในเบราว์เซอร์ คอมพิวเตอร์ของคุณยังมีจุดอ่อนนี้อยู่ เพราะการส่งต่อพอร์ตของ SSH ตรงนั้นก็รอรับการเชื่อมต่อที่พอร์ต <code dir="ltr">127.0.0.1</code> เช่นกัน
</Aside>

## ถัดไป

- [เชื่อมต่อผ่าน SSH](../remote-connections/): สำหรับเซิร์ฟเวอร์ Linux หรือเมื่อต้องการใช้แอปบนเดสก์ท็อป
- [เบราว์เซอร์ผ่าน Tailscale](../browser-over-tailscale/): เบราว์เซอร์เท่านั้น ใช้ได้กับโฮสต์ทุกแบบ ไม่ต้องใช้ SSH
- [เบราว์เซอร์ผ่าน UU Remote](../browser-over-uu-remote/): เบราว์เซอร์เท่านั้น โฮสต์ Mac หรือ Windows ไม่ต้องใช้ SSH
