{productName} ปล่อยให้ระบบของคุณเป็นอย่างที่เคยเป็น ทั้งการกำหนดค่าของเอเจนต์ และทุกอย่างที่อยู่นอกโฟลเดอร์ของ {productName} เอง มีฟีเจอร์เพียงไม่กี่ตัวที่เพิ่มบางอย่างไว้นอกโฟลเดอร์เหล่านั้น หน้านี้แสดงรายการทั้งหมด พร้อมบอกว่าแต่ละตัวเพิ่มอะไร ที่ไหน และยกเลิกได้อย่างไร รวมถึงบอกว่าเหลืออะไรหลังจากที่คุณถอนการติดตั้ง

## กฎ

- <strong>สิ่งที่ {productName} ให้กับเอเจนต์จะไปถึงเอเจนต์ในแต่ละครั้งที่เริ่มทำงาน และเฉพาะตอนนั้นเท่านั้น</strong> ฮุกสถานะ เซิร์ฟเวอร์ MCP ของ {productName} เอง และบทบาทที่อธิบายให้เซสชันทราบ จะถูกส่งให้ตอนที่เอเจนต์เริ่มทำงาน หรือเก็บไว้ในโฟลเดอร์ของ {productName} เอง ไม่มีไฟล์ของคุณหรือของเอเจนต์ถูกแก้ไขเพื่อการนี้ ดังนั้นเอเจนต์ที่คุณรันเองจะเริ่มทำงานโดยไม่มีสิ่งเหล่านี้เลย
- <strong>{productName} ไม่เพิ่มฮุกของตัวเองลงในการตั้งค่าของคุณ และไม่ตัดสินใจเรื่องโฟลเดอร์ของโปรเจกต์แทนคุณ</strong> จะเชื่อถือโฟลเดอร์ของโปรเจกต์หรือไม่ คุณเป็นผู้บอก และเอเจนต์เป็นผู้บันทึก โฟลเดอร์เดียวที่ {productName} ตอบเองคือโฟลเดอร์ของคอนโซลเอง ซึ่งเป็นของ {productName} (ดูด้านล่าง)
- <strong>สิ่งที่เอเจนต์เขียนให้ตัวเองเป็นของเอเจนต์</strong> บันทึกการสนทนา แคชและล็อก ข้อมูลประจำตัวของการเข้าสู่ระบบ และความเชื่อถือที่เอเจนต์บันทึกเมื่อคำถามของเอเจนต์เองได้รับคำตอบ ถูกเขียนเหมือนกับตอนที่คุณใช้เอเจนต์โดยไม่มี {productName} การตั้งค่าเริ่มแรกที่โปรแกรมของเอเจนต์เองทำเมื่อรันครั้งแรกในโฟลเดอร์การกำหนดค่าก็เช่นกัน การอ่านข้อมูลเบื้องหลังของ {productName} อาจทำให้ขั้นตอนนี้เกิดขึ้นก่อนที่คุณจะเริ่มใช้งานครั้งแรกเอง (ดูด้านล่าง)
- <strong>งานภายในโปรเจกต์ของคุณไม่ใช่เรื่องของหน้านี้</strong> การแก้ไขไฟล์ของโปรเจกต์ การทำงานกับ Git แบรนช์ และเวิร์กทรี คืองานพัฒนาที่คุณเพิ่มโปรเจกต์เข้ามาเพื่อทำ

## ฟีเจอร์เพิ่มอะไร และยกเลิกได้อย่างไร

แต่ละรายการต่อไปนี้ถูกเพิ่มโดยฟีเจอร์ที่คุณใช้หรือเปิดไว้เท่านั้น

### ยกเลิกได้ด้วยการปิดฟีเจอร์

- <strong>คีย์ของคอมพิวเตอร์เครื่องนี้บนเซิร์ฟเวอร์ระยะไกล</strong> หลังจากที่คุณลงชื่อเข้าใช้ดีมอนระยะไกลที่บันทึกไว้ด้วยรหัสผ่านหรือไฟล์คีย์ แอปจะถามก่อนเพิ่มสิ่งใด โดยกล่องโต้ตอบ <strong>เพิ่มคีย์ของคอมพิวเตอร์เครื่องนี้</strong> จะระบุไฟล์และบรรทัด <strong>เพิ่มคีย์</strong> จะเพิ่มหนึ่งบรรทัดที่มีเครื่องหมาย <code dir="ltr">{system.keyMark}</code> ลงในคีย์ SSH ที่อนุญาตของผู้ใช้ของคุณบนเซิร์ฟเวอร์นั้น (<code dir="ltr">{commands.authorizedKeys}</code> บน Linux และ macOS) และเก็บคีย์ส่วนตัวไว้ในที่เก็บข้อมูลประจำตัวของคอมพิวเตอร์เครื่องนี้ (พวงกุญแจเข้าสู่ระบบบน macOS และ Credential Manager บน Windows) <strong>ไม่เพิ่ม</strong> จะไม่เพิ่มอะไรเลย และจะไม่ถามอีก หากต้องการยกเลิก ให้ปิด <strong>คีย์ของคอมพิวเตอร์เครื่องนี้</strong> ในหน้าของดีมอนนั้นใน <strong>อุปกรณ์ระยะไกล</strong> หรือเอาดีมอนที่บันทึกไว้ออก แอปจะลบบรรทัดนั้นออกจากไฟล์และลบคีย์ส่วนตัว แอปทำเช่นเดียวกันเมื่อคุณเปลี่ยนโฮสต์ พอร์ต หรือผู้ใช้ของดีมอนที่บันทึกไว้ หากเชื่อมต่อเซิร์ฟเวอร์ไม่ได้ บรรทัดนั้นอาจยังอยู่ แอปจะแจ้งให้คุณทราบ เพื่อให้คุณลบเองบนเซิร์ฟเวอร์
- <strong>เปิดเมื่อเข้าสู่ระบบ</strong> (Windows และ macOS 13 ขึ้นไป) <strong>การตั้งค่า › ทั่วไป › เปิดเมื่อเข้าสู่ระบบ</strong> จะใส่ {productName} ไว้ในรายการแอปที่ระบบของคุณเปิดเมื่อเข้าสู่ระบบ และแถวการตั้งค่านี้ก็บอกไว้เช่นนั้น การปิดสวิตช์นี้คือวิธีเอา {productName} ออกจากรายการนั้น
- <strong>เครื่องมือบรรทัดคำสั่ง</strong> (macOS) <strong>ติดตั้ง</strong> ใน <strong>การตั้งค่า › ทั่วไป › เครื่องมือบรรทัดคำสั่ง</strong> จะเพิ่มลิงก์ชื่อ <code dir="ltr">{system.cliName}</code> ไว้ใน <code dir="ltr">{system.cliDir}</code> หรือใน <code dir="ltr">{system.cliFallbackDir}</code> หากระบบไม่อนุญาต แถวการตั้งค่านี้บอกไว้ก่อนที่คุณจะติดตั้ง <strong>ลบ</strong> จะลบลิงก์นั้น
- <strong>การใช้การกำหนดค่าเริ่มต้นร่วมกัน</strong> <strong>ใช้การกำหนดค่าเริ่มต้นร่วมกัน</strong> ในการตั้งค่าของบัญชีภายใต้ <strong>การตั้งค่า › บัญชีเอเจนต์</strong> จะแทนที่ส่วนที่ใช้ร่วมกันได้ในโฟลเดอร์ของบัญชีนั้นด้วยลิงก์ไปยังโฟลเดอร์ของบัญชีเริ่มต้น เก็บการกำหนดค่าของบัญชีเองไว้เป็นข้อมูลสำรองข้าง ๆ และย้ายประวัติการสนทนาของบัญชีไปไว้ในโฟลเดอร์ของบัญชีเริ่มต้น แถวการตั้งค่านี้บอกไว้ก่อนที่คุณจะเปิด เมื่อปิด ลิงก์จะถูกเอาออก ข้อมูลสำรองจะถูกกู้คืน และบทสนทนาของเซสชันของบัญชีนั้นเองจะถูกย้ายกลับ <strong>มีสิ่งหนึ่งที่ยังอยู่</strong> คือประวัติการสนทนาส่วนที่เหลือซึ่งถูกย้ายไปแล้วจะยังอยู่ในโฟลเดอร์ของบัญชีเริ่มต้น เพราะการเอาออกจะทำให้คุณเสียบทสนทนาไป ดู [Shared configuration](../features/shared-configuration/)

### คงไว้เป็นของคุณหรือของเอเจนต์

การทำงานเหล่านี้เขียนสิ่งที่นับจากนั้นเป็นของคุณหรือของเอเจนต์ {productName} จึงไม่มีอะไรของตัวเองที่ต้องยกเลิก หากรายการใดลบด้วยตนเองได้ หัวข้อนั้นจะบอกว่าอยู่ที่ไหน

- <strong>การสลับบัญชีของเซสชัน</strong> <strong>สลับบัญชี</strong> จะขอให้คุณยืนยันก่อน การสลับที่เอเจนต์ร้องขอจะรอการอนุมัติจากคุณ เว้นแต่คุณจะเปิด <strong>อนุมัติการสลับบัญชีอัตโนมัติ</strong> ไว้ และการสลับเมื่อถึงขีดจำกัดการใช้งานจะเกิดขึ้นเฉพาะขณะที่ <strong>สลับบัญชีอัตโนมัติเมื่อถึงขีดจำกัดการใช้งาน</strong> เปิดอยู่ การสลับจะคัดลอกบทสนทนาของเซสชันนั้นเพียงเซสชันเดียวไปยังโฟลเดอร์ของบัญชีปลายทาง สำหรับ Codex ยังชี้บันทึกของบัญชีนั้นเองเกี่ยวกับบทสนทนาไปยังสำเนาด้วย ต้นฉบับยังอยู่ที่เดิม และสำเนาจะคงอยู่เป็นของบัญชีนั้นเอง ดู [Account continuity](../features/account-continuity/)
- <strong>การตั้งค่าและปลั๊กอินที่คุณเปลี่ยนภายในเซสชัน Grok Build</strong> หาก <code dir="ltr">config.toml</code> ของคุณเป็นลิงก์ไปยังไฟล์ ธีม สวิตช์ปลั๊กอิน หรือโมเดลเริ่มต้นที่คุณเปลี่ยนในเซสชันจะถูกเขียนลงในไฟล์นั้นเมื่อเซสชันสิ้นสุด เช่นเดียวกับที่ Grok บันทึกเอง ปลั๊กอินที่คุณติดตั้งในเซสชันจะถูกบันทึกไว้ในรีจิสทรีปลั๊กอินของโฟลเดอร์ Grok ของคุณเอง หากมี
- <strong>ความเชื่อถือของ Grok Build ต่อโฟลเดอร์ของโปรเจกต์</strong> เมื่อคุณตกลงเชื่อถือโฟลเดอร์ของโปรเจกต์แล้ว (เลือก <strong>เชื่อถือและดำเนินต่อ</strong> หรือตอบเองในเทอร์มินัล) รายการเดียวที่ Grok เขียนไว้จะถูกนำไปใส่ในรายการความเชื่อถือในโฟลเดอร์ Grok ของคุณโดยไม่เปลี่ยนแปลง
- <strong>บันทึกของเซสชันที่ไม่เคยมีบทสนทนา</strong> การลบเซสชันที่คุณไม่เคยส่งอะไรเข้าไป จะย้ายบันทึกของเอเจนต์เองเกี่ยวกับเซสชันนั้นไปยังถังขยะ (ถังรีไซเคิลบน Windows) พร้อมกันโดยไม่ถาม เพราะในนั้นไม่มีบทสนทนาของคุณ บันทึกของเซสชันที่คุณเคยใช้จะถูกย้ายเฉพาะเมื่อคุณเลือกตัวเลือกนั้นในกล่องยืนยัน และกู้คืนได้จากถังขยะ
- <strong>การตั้งค่าเมื่อรันครั้งแรกของ Claude Code</strong> ในโฟลเดอร์การกำหนดค่าที่ Claude Code ยังไม่เคยรัน หรือหลังจากอัปเดต Claude Code การอ่านข้อมูลเบื้องหลังของ {productName} (การใช้งานของบัญชี เซิร์ฟเวอร์ MCP หรือเอเจนต์ของบัญชี) จะทำให้ Claude Code ทำการตั้งค่าเมื่อรันครั้งแรกและการย้ายข้อมูลที่ค้างอยู่ของตัวเองที่นั่น เช่นเดียวกับที่การเริ่มใช้งานครั้งถัดไปของคุณจะทำ {productName} ปล่อยการเปลี่ยนแปลงเหล่านั้นไว้ตามเดิม
- <strong>โฟลเดอร์ว่างสำหรับบัญชี Codex ใหม่</strong> ก่อนที่บัญชี Codex จะเริ่มทำงานหรือลงชื่อเข้าใช้ครั้งแรก {productName} จะสร้างโฟลเดอร์ของบัญชีนั้นเป็นโฟลเดอร์ว่าง หากยังไม่มี เพราะหากไม่มีโฟลเดอร์นี้ Codex จะไม่ยอมเริ่มทำงาน
- <strong>ความเชื่อถือต่อโฟลเดอร์ของคอนโซลเอง</strong> เซสชันคอนโซลทำงานในโฟลเดอร์ของ {productName} เอง {productName} จึงตอบคำถามเรื่องความเชื่อถือของเอเจนต์ที่นั่นโดยไม่ถามคุณ จากนั้น Claude Code จะเก็บรายการหนึ่งไว้ในรายการความเชื่อถือของตัวเอง ซึ่งระบุเฉพาะโฟลเดอร์นั้น และไม่มีผลกับที่อื่นใด Codex จะถามเฉพาะเมื่อโฟลเดอร์นั้นอยู่ภายในที่เก็บ Git แล้วบันทึกความเชื่อถือสำหรับรากของที่เก็บนั้น ซึ่งครอบคลุมที่เก็บทั้งหมด หากโฟลเดอร์โฮมของคุณอยู่ใน Git ก็หมายถึงโฟลเดอร์โฮมทั้งหมด ส่วน Grok Build ไม่บันทึกอะไรลงในรายการความเชื่อถือของคุณ {productName} จะไม่ลบรายการเหล่านี้ เพราะนั่นจะเป็นการแก้ไขไฟล์ของคุณอีกครั้งหนึ่ง คุณลบเองได้ รายการของ Codex คือตาราง <code dir="ltr">[projects."&lt;repository root&gt;"]</code> ใน <code dir="ltr">config.toml</code> ในโฟลเดอร์ของ Codex และรายการของ Claude Code คือรายการของโฟลเดอร์นั้นภายใต้ <code dir="ltr">projects</code> ใน <code dir="ltr">.claude.json</code> ของ Claude Code

### ยกเลิกได้ด้วยคำสั่งถอนการติดตั้ง

- <strong>โปรแกรมเซิร์ฟเวอร์ Linux ที่ทำงานเป็นบริการ</strong> การติดตั้งเป็นบริการ (ดู [เซิร์ฟเวอร์ Linux](../install/linux/)) จะเขียนบริการผู้ใช้ของ systemd ลงในโฟลเดอร์การกำหนดค่า systemd ของคุณ และเปิด lingering ให้ผู้ใช้ของคุณหากปิดอยู่ วิธียกเลิกคือคำสั่งถอนการติดตั้งด้านล่าง

<Aside>
บน Windows แอปยังดูแล Jump List ของปุ่มบนแถบงาน ซึ่งมีดีมอนระยะไกลที่คุณบันทึกไว้ รายการนี้ไม่มีสวิตช์ <strong>ลบทั้งหมด</strong> ที่อธิบายไว้ด้านล่างจะลบรายการนี้ และตัวถอนการติดตั้งก็ลบเช่นกัน
</Aside>

## ก่อนถอนการติดตั้ง

ก่อนถอนการติดตั้ง ทุกอย่างจากหัวข้อ “ยกเลิกได้ด้วยการปิดฟีเจอร์” ที่มีผลอยู่สามารถลบได้ในครั้งเดียว พร้อมปิดฟีเจอร์ของแต่ละรายการ ในแอปเดสก์ท็อป <strong>การตั้งค่า › การล้างข้อมูล</strong> มีแถวหนึ่งสำหรับเรื่องนี้ คือ <strong>เก็บกวาดก่อนถอนการติดตั้ง</strong> ซึ่งบอกว่ามีกี่รายการที่มีผลอยู่ และมีปุ่มเดียวคือ <strong>ลบทั้งหมด</strong> บน Windows ตัวถอนการติดตั้งก็ทำสิ่งนี้เองด้วย ส่วนคำสั่งถอนการติดตั้งของโปรแกรมเซิร์ฟเวอร์ Linux จะทำสิ่งนี้เป็นอย่างแรก ทั้งสองแบบอธิบายไว้ด้านล่าง

- <strong>ถามก่อนเสมอ</strong> หน้ายืนยันบอกว่าจะลบกี่รายการ โดยรายการทั้งหมดพับเก็บอยู่ใต้จำนวนนั้น และบอกว่าอะไรจะถูกเก็บไว้ จะดำเนินการต่อก็ต่อเมื่อคุณพิมพ์ <strong>ลบ</strong> แล้วเท่านั้น
- <strong>แสดงผลลัพธ์</strong> หลังจากนั้นจะแสดงรายการว่าอะไรถูกลบแล้วและอะไรยังไม่ถูกลบ สำหรับรายการที่ลบไม่ได้ เช่น คีย์บนเซิร์ฟเวอร์ที่เชื่อมต่อไม่ได้ จะบอกว่าเหลืออะไรและอยู่ที่ไหน
- <strong>มีเฉพาะในหน้าต่างของแอปเองบนคอมพิวเตอร์เครื่องนั้น</strong> ในเบราว์เซอร์บนคอมพิวเตอร์ที่มีแอปเดสก์ท็อป และในหน้าต่างที่แสดงดีมอนระยะไกล แถวนี้บอกเพียงว่าทำการเก็บกวาดได้ที่ไหน ในเบราว์เซอร์ที่เปิดเซิร์ฟเวอร์ Linux แถวนี้บอกว่าการถอนการติดตั้งบนเซิร์ฟเวอร์จะเก็บกวาดก่อน และแสดง <code dir="ltr">{system.uninstall}</code> พร้อม <strong>คัดลอกคำสั่งถอนการติดตั้ง</strong> ให้คุณนำไปรันบนเซิร์ฟเวอร์ ไม่มีอะไรถูกลบจากที่นั่น
- <strong>ใช้เฉพาะเมื่อคุณกำลังถอนการติดตั้ง</strong> หากต้องการยกเลิกเพียงรายการเดียวและใช้ {productName} ต่อ ให้ปิดฟีเจอร์นั้นแทน
- <strong>เก็บข้อมูลของคุณไว้</strong> โฟลเดอร์ของ {productName} เองยังอยู่ และประวัติการสนทนาที่ถูกย้ายเพราะการใช้ร่วมกันก็ยังอยู่เช่นกัน

## หลังถอนการติดตั้ง

การถอนการติดตั้งจะลบโปรแกรม

### macOS

ออกจาก {productName} แล้วลบออกจากโฟลเดอร์แอปพลิเคชัน ไม่มีอะไรทำงานเมื่อแอปถูกลบ จึงควรเลือก <strong>ลบทั้งหมด</strong> ก่อน เพราะการลบแอปจะไม่ลบสิ่งที่การทำงานนี้ลบ

### เซิร์ฟเวอร์ Linux

<LinuxUninstall />

โฟลเดอร์ที่ติดตั้งโปรแกรมไว้จะยังอยู่ รวมถึงบรรทัดใดๆ ที่คุณเพิ่มเพื่อใส่โฟลเดอร์นั้นใน PATH

### สิ่งที่ยังอยู่

โฟลเดอร์ของ {productName} เองจะถูกเก็บไว้ การติดตั้งครั้งต่อไปจึงพบคอนโซล เซสชัน และการตั้งค่าของคุณอีกครั้ง หากต้องการลบสิ่งเหล่านี้ด้วย ให้ลบโฟลเดอร์ดังกล่าว คุณจะเสียคอนโซล บันทึกเซสชัน และการตั้งค่าทั้งหมด

- <strong>โฟลเดอร์ข้อมูล</strong> บนคอมพิวเตอร์หรือเซิร์ฟเวอร์ที่เซสชันทำงาน: <code dir="ltr">{system.dataDir}</code> (<code dir="ltr">{system.dataDirWindows}</code> บน Windows) บน macOS และ Linux คำสั่ง <code dir="ltr">{system.removeDataDir}</code> จะลบโฟลเดอร์นี้
- <strong>โฟลเดอร์ของแอปเดสก์ท็อปเอง:</strong> <code dir="ltr">{system.appDataMac}</code> บน macOS และ <code dir="ltr">{system.appDataWindows}</code> กับ <code dir="ltr">{system.appLocalDataWindows}</code> บน Windows

โฟลเดอร์ของเอเจนต์เอง พร้อมการเข้าสู่ระบบ การตั้งค่า และบทสนทนา เป็นของเอเจนต์และยังคงเป็นอย่างที่เป็นอยู่
