{productName} คือพื้นที่ทำงานสำหรับนักพัฒนาที่ทำงานบนเครื่องของคุณเอง เป็นโอเพนซอร์ส และออกแบบมาสำหรับเอเจนต์เขียนโค้ด โดยรวมเอเจนต์และบัญชีที่คุณมีอยู่แล้วไว้ในที่เดียว คุณรันเซสชันหลายอันเคียงข้างกันได้ สลับบัญชีโดยยังคงบทสนทนาเดิม ส่งต่องานระหว่างผู้ให้บริการได้ และให้เอเจนต์ผู้ประสานงานกระจายงานไปยังหลายโปรเจ็กต์ได้

เอเจนต์เขียนโค้ดคือผู้ช่วย AI ที่เขียนและรันโค้ดให้คุณ เช่น Claude Code หรือ Codex {productName} ไม่ได้มีเอเจนต์มาให้ แต่ใช้เอเจนต์ที่คุณมีอยู่แล้ว

## เริ่มต้นที่ไหนดี

- **ใช้ {productName} บนคอมพิวเตอร์เครื่องนี้:** ติดตั้งแอปสำหรับ [macOS](install/macos/) หรือ [Windows](install/windows/) คนส่วนใหญ่ทำเพียงเท่านี้ก็พอ
- **รันเอเจนต์บนเซิร์ฟเวอร์ Linux** (เครื่องที่เช่าไว้หรือเปิดทิ้งไว้ที่ไหนสักแห่ง ซึ่งมักไม่มีหน้าจอ): [ติดตั้งโปรแกรมเซิร์ฟเวอร์](install/linux/) แล้วเชื่อมต่อจากแอปบนเดสก์ท็อป ตามที่ [เชื่อมต่อผ่าน SSH](remote-connections/) อธิบายไว้
- **ใช้ {productName} ของคอมพิวเตอร์เครื่องหนึ่งจากอีกเครื่อง:** เริ่มที่ [เลือกวิธีเชื่อมต่อ](choose-how-to-connect/) ซึ่งเปรียบเทียบวิธีเข้าถึงต่าง ๆ สรุปสั้น ๆ คือ
  - จากแอปของอีกเครื่อง หรือจากเบราว์เซอร์ โดยเปิดการลงชื่อเข้าใช้ด้วย SSH: [เชื่อมต่อผ่าน SSH](remote-connections/)
  - จากเบราว์เซอร์ โดยไม่ต้องเปิดการลงชื่อเข้าใช้ด้วย SSH: [เบราว์เซอร์ผ่าน Tailscale](browser-over-tailscale/) หรือ
    [เบราว์เซอร์ผ่าน UU Remote](browser-over-uu-remote/)
