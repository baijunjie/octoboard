ติดตั้ง octoboardd ซึ่งเป็นโปรแกรมเซิร์ฟเวอร์ของ {productName} (แอปเรียกว่า “ดีมอน”) บนเซิร์ฟเวอร์ Linux โดยไม่ต้องใช้สิทธิ์ root เข้าถึงได้จากแอป macOS หรือ Windows หรือจากเบราว์เซอร์ ทั้งสองวิธีผ่าน SSH

รองรับ x86_64 และ aarch64 บนดิสทริบิวชันใดก็ได้

<Aside>โปรแกรมเซิร์ฟเวอร์ Linux อยู่ในช่วงเบต้า</Aside>

## ก่อนเริ่ม

- **เซิร์ฟเวอร์ Linux ที่คุณลงชื่อเข้าใช้ด้วย SSH ได้** SSH คือวิธีที่ปลอดภัยในการลงชื่อเข้าใช้เครื่องอื่นและพิมพ์คำสั่งบนเครื่องนั้น ผู้ให้บริการเซิร์ฟเวอร์จะให้ที่อยู่ของเซิร์ฟเวอร์และชื่อผู้ใช้ของคุณ
- **แอป {productName} บนคอมพิวเตอร์ของคุณเอง** สำหรับ [macOS](../macos/) หรือ [Windows](../windows/) หากคุณต้องการทำงานในแอปบนเดสก์ท็อป (แนะนำ)

ในการลงชื่อเข้าใช้ ให้เปิด Terminal (macOS) หรือ PowerShell (Windows) บนคอมพิวเตอร์ของคุณเอง แล้วรันคำสั่งด้านล่าง โดยใส่ชื่อผู้ใช้ของคุณแทน <code dir="ltr">&lt;you&gt;</code> และใส่ที่อยู่ของเซิร์ฟเวอร์แทน <code dir="ltr">{commands.server}</code> ครั้งแรกให้ตอบ <code dir="ltr">yes</code> เมื่อมันถามว่าจะเชื่อถือเซิร์ฟเวอร์หรือไม่

<Code code={commands.signIn} lang="sh" />

ขั้นตอนที่ 1 และ 2 ด้านล่างรันบนเซิร์ฟเวอร์ ในหน้าต่างที่ลงชื่อเข้าใช้แล้วนี้

## ติดตั้ง

<Steps>

1. ติดตั้ง octoboardd บนเซิร์ฟเวอร์

   <Code code={commands.install} lang="sh" />

   มันจะแสดงบรรทัดที่ขึ้นต้นด้วย <code dir="ltr">Installed octoboardd</code>
2. เริ่มทำงานบนเซิร์ฟเวอร์

   <Code code={commands.start} lang="sh" />

   มันจะแสดงบรรทัดที่ขึ้นต้นด้วย <code dir="ltr">{productName} started</code>
3. เชื่อมต่อจากคอมพิวเตอร์ของคุณเอง ได้สองวิธี

   - <strong>จากแอปบนเดสก์ท็อป (แนะนำ):</strong> ทำตาม [เชื่อมต่อกับเซิร์ฟเวอร์ Linux](../../remote-connections/#เชื่อมต่อกับเซิร์ฟเวอร์-linux) ในคู่มือ SSH
   - <strong>จากเบราว์เซอร์:</strong> รันคำสั่งนี้บนเซิร์ฟเวอร์

     <Code code={commands.address} lang="sh" />

     มันจะแสดงสองอย่าง คือที่อยู่ของเบราว์เซอร์ ซึ่งขึ้นต้นด้วย <code dir="ltr">http://127.0.0.1:</code> และคำสั่ง <code dir="ltr">ssh</code> บนคอมพิวเตอร์ของคุณเอง ให้คัดลอกคำสั่ง <code dir="ltr">ssh</code> แทนที่ <code dir="ltr">{commands.server}</code> ด้วยที่อยู่ของเซิร์ฟเวอร์ (ที่อยู่ IP หรือชื่อที่คุณใช้ลงชื่อเข้าใช้) แล้วรันใน Terminal หรือ PowerShell มันอาจถามรหัสผ่านของคุณ จากนั้นจะไม่แสดงอะไรอีก ซึ่งเป็นเรื่องปกติ เปิดหน้าต่างนั้นทิ้งไว้ เพราะถ้าปิด การเชื่อมต่อจะขาด จากนั้นเปิดที่อยู่ที่แสดงไว้ในเบราว์เซอร์ของคุณ

</Steps>

คุณจะรู้ว่าสำเร็จเมื่อ {productName} เปิดขึ้นในหน้าต่างใหม่ของแอปบนเดสก์ท็อป หรือในแท็บของเบราว์เซอร์

## หากไม่พบ octoboardd

หากการติดตั้งแจ้งว่าโฟลเดอร์ที่ลงท้ายด้วย <code dir="ltr">.local/bin</code> (เช่น <code dir="ltr">/home/&lt;you&gt;/.local/bin</code>) ไม่อยู่ใน PATH แปลว่าเชลล์หาโปรแกรม <code dir="ltr">octoboardd</code> จากชื่อไม่เจอ ให้รันด้วยพาธเต็มที่การติดตั้งแสดงไว้ หรือเพิ่ม <code dir="ltr">{commands.binDir}</code> ลงใน PATH ของคุณ (เช่นในไฟล์ <code dir="ltr">~/.profile</code>) แล้วลงชื่อเข้าใช้ใหม่

## ให้ทำงานต่อหลังออกจากระบบหรือรีบูต

เมื่อเริ่มด้วย <code dir="ltr">{commands.start}</code> octoboardd จะหยุดเมื่อเซิร์ฟเวอร์รีสตาร์ท และไม่มีอะไรเริ่มมันใหม่ให้เอง ให้รัน <code dir="ltr">{commands.start}</code> อีกครั้ง หรือเชื่อมต่อจากแอปบนเดสก์ท็อป ซึ่งจะเสนอเริ่มให้คุณ เซิร์ฟเวอร์บางเครื่องยังหยุดมันเมื่อคุณออกจากระบบด้วย

หากต้องการให้เริ่มทำงานทุกครั้งที่เซิร์ฟเวอร์เริ่มและทำงานต่อหลังคุณออกจากระบบ ให้ติดตั้งเป็นบริการแทน

<Code code={commands.installService} lang="sh" />

คำสั่งนี้ติดตั้งโปรแกรม ตั้งค่าเป็นบริการผู้ใช้ของ systemd และเริ่มทำงาน จากนั้นจะเปิด lingering ซึ่งทำให้บริการของคุณทำงานได้ขณะที่คุณไม่ได้ลงชื่อเข้าใช้ หากมันแจ้งว่าทำไม่ได้ ให้รันคำสั่งนี้หนึ่งครั้ง (อาจต้องใช้ <code dir="ltr">sudo</code>)

<Code code={commands.linger} lang="sh" />

octoboardd เลือกพอร์ตของตัวเองโดยที่คุณไม่ต้องรู้เลย ที่อยู่และคำสั่ง <code dir="ltr">ssh</code> ที่ <code dir="ltr">{commands.address}</code> แสดงจะระบุพอร์ต <code dir="ltr">{commands.defaultPort}</code> ซึ่งเป็นเลขเดิมทุกครั้ง

## อัปเกรด

{productName} ไม่เคยอัปเกรดตัวเองโดยพลการ เมื่อมีเวอร์ชันใหม่ เบราว์เซอร์จะแจ้งให้คุณทราบ และคุณเป็นผู้เลือกว่าจะติดตั้งเมื่อไร เมื่อติดตั้งเวอร์ชันใหม่แล้ว {productName} จะรีสตาร์ทเป็นเวอร์ชันนั้นเอง หากไม่มีเซสชันใดถูกขัดจังหวะ แต่หากมี มันจะแสดงรายการเซสชันเหล่านั้นและถามก่อน

- <strong>ในเบราว์เซอร์:</strong> เลือก <strong>ดาวน์โหลดและติดตั้ง</strong> ตรงที่แจ้งว่ามีเวอร์ชันใหม่
- <strong>บนเซิร์ฟเวอร์:</strong> รันคำสั่งนี้

  <Code code={commands.update} lang="sh" />

  หากมันถามว่าจะรีสตาร์ททันทีหรือไม่ ให้ตอบ <code dir="ltr">y</code> เพื่อรีสตาร์ท หรือกด Enter เพื่อให้เวอร์ชันเก่าทำงานต่อไปก่อน หากต้องการรีสตาร์ทภายหลัง ให้รัน <code dir="ltr">{commands.restart}</code>

หาก <code dir="ltr">{commands.update}</code> แจ้งว่าแทนที่โปรแกรมไม่ได้ เช่นเพราะติดตั้งไว้ในที่ที่คุณเขียนไม่ได้ ให้รันคำสั่งติดตั้ง (หรือคำสั่งบริการ) อีกครั้งแทน มันจะรีสตาร์ทในแบบเดียวกันเมื่อปลอดภัย และหากไม่ ก็จะบอกให้คุณรัน <code dir="ltr">{commands.restart}</code>
