{productName} tidak pernah membuka dirinya ke jaringan, jadi komputer lain memerlukan jalur yang aman untuk mencapainya. SSH adalah login terenkripsi standar yang sudah ada di macOS, Windows, dan Linux, dan menjadi jalan masuk utama: dari aplikasi desktop atau dari browser. Jika Anda tidak ingin mengaktifkan login SSH di host, relay pihak ketiga, Tailscale atau UU Remote, dapat membawa koneksi browser sebagai gantinya.

<strong>Host</strong> adalah mesin tempat {productName} berjalan dan yang ingin Anda jangkau.

<Aside type="tip" title="Cara paling sederhana">
Jika sedikit jeda input dan gambar yang buram tidak masalah bagi Anda, Anda tidak perlu pengaturan mana pun di bawah ini: buka host lewat desktop jarak jauh [UU Remote](https://uuyc.163.com/) dan gunakan {productName} langsung di host. Cara ini berlaku untuk host Mac atau Windows, bukan server Linux. Antarmuka UU Remote berbahasa Mandarin. Untuk jendela yang tajam dan responsif di komputer Anda sendiri, pilih salah satu cara di bawah.
</Aside>

## Sebelum memilih relay

Panduan relay memerlukan lebih banyak langkah daripada SSH: Anda menjalankan perintah di kedua komputer dan membiarkannya tetap berjalan di jendela yang terbuka selama Anda bekerja.

<Aside type="caution">
Panduan Tailscale dan UU Remote belum diuji sepenuhnya di antara dua perangkat. Keduanya mengikuti dokumentasi layanan tersebut dan pemeriksaan {productName} sendiri.
</Aside>

<Aside type="caution" title="Hanya di komputer yang tidak dipakai login orang lain">
Dengan relay, akun pengguna lain di host atau di komputer Anda sendiri dapat menangkap kunci browser. Pakai Tailscale atau UU Remote hanya di komputer yang hanya Anda yang login. [Terhubung melalui SSH](../remote-connections/) tidak memiliki kelemahan ini di host Linux dengan akses browser nonaktif, maupun di host Mac atau Windows yang dipakai dari aplikasi desktop, dan komputer Anda sendiri juga tidak memilikinya saat memakai aplikasi desktop. Di browser, komputer Anda tetap memilikinya, karena penerusan SSH di sana juga mendengarkan di port <code dir="ltr">127.0.0.1</code>.
</Aside>
