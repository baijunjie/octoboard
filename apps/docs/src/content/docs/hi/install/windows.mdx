## इंस्टॉल करें

<Steps>

1. ऊपर दिए बटन से इंस्टॉलर डाउनलोड करें। यह ऐसी फ़ाइल है जिसके नाम का अंत <code dir="ltr">x64-setup.exe</code> से होता है।
2. इंस्टॉलर चलाने के लिए डाउनलोड की गई फ़ाइल खोलें। यह {productName} को सिर्फ़ आपके यूज़र अकाउंट के लिए इंस्टॉल करता है, इसलिए एडमिनिस्ट्रेटर की अनुमति नहीं माँगता।

   ऐप पर अभी कोड-साइन नहीं है, इसलिए Microsoft Defender SmartScreen “Windows protected your PC” दिखा सकता है। “More info” चुनें, फिर “Run anyway”।

   अगर आपके PC में Microsoft Edge WebView2 नहीं है, जो ऐप की विंडो बनाता है, तो इंस्टॉलर उसे डाउनलोड करता है, इसलिए इंटरनेट से जुड़े रहें।
3. {productName} को Start मेन्यू से खोलें।
4. कम से कम एक कोडिंग एजेंट इंस्टॉल करें (नीचे देखें), फिर {productName} में <strong>प्रोजेक्ट जोड़ें</strong> चुनकर कोई प्रोजेक्ट फ़ोल्डर खोलें।

</Steps>

मुख्य विंडो खुल जाए, तो काम पूरा हुआ।

## कोडिंग एजेंट इंस्टॉल करें

{productName} में कोई AI एजेंट शामिल नहीं है। जिन्हें आप इस्तेमाल करना चाहते हैं, उन्हें उनके अपने निर्देशों के अनुसार इंस्टॉल करें और उनमें साइन इन करें। {productName} उन्हें अपने आप ढूँढ लेता है। यह इनके साथ काम करता है:

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)

अगर आप Claude Code या Codex इस्तेमाल करते हैं, तो पहले [Git for Windows](https://git-scm.com/download/win) इंस्टॉल करें; उन्हें काम करने के लिए इसकी ज़रूरत होती है।
