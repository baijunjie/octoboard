## इंस्टॉल करें

<Steps>

1. ऊपर दिए बटन से ऐप डाउनलोड करें। आपको एक डिस्क इमेज मिलेगी, यानी ऐसी फ़ाइल जिसके नाम का अंत <code dir="ltr">.dmg</code> से होता है।
2. डाउनलोड की गई फ़ाइल खोलें। जो विंडो खुले उसमें {productName} को Applications फ़ोल्डर पर खींचकर छोड़ें।
3. {productName} को Applications फ़ोल्डर या Launchpad से खोलें।
4. कम से कम एक कोडिंग एजेंट इंस्टॉल करें (नीचे देखें), फिर {productName} में <strong>प्रोजेक्ट जोड़ें</strong> चुनकर कोई प्रोजेक्ट फ़ोल्डर खोलें।

</Steps>
