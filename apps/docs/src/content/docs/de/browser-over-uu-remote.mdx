Öffne {productName} in einem Browser auf einem anderen Computer über die Portzuordnung von [UU Remote](https://uuyc.163.com/), der Fernsteuerungs-App von NetEase, ohne SSH und ohne Remote-Desktop. Der Host ist der Computer, auf dem {productName} läuft; die SSH-Anmeldung (Entfernte Anmeldung unter macOS) kann ausgeschaltet bleiben, und eine Remote-Desktop-Sitzung ist nicht nötig. Die Oberfläche von UU Remote ist auf Chinesisch, deshalb nennt diese Anleitung ihre chinesischen Bezeichnungen neben den deutschen.

Diese Anleitung öffnet {productName} in einem Browser auf deinem eigenen Computer. Das ist schärfer und reaktionsschneller als Remote-Desktop, braucht aber mehr Schritte. Wenn dir etwas Verzögerung und Unschärfe nichts ausmachen, arbeite einfach über den Remote-Desktop von UU Remote direkt auf dem Host.

Du bist nicht sicher, ob das der richtige Weg für dich ist? Siehe [Verbindungsart wählen](../choose-how-to-connect/).

<Aside type="caution">
Diese Schritte wurden noch nicht zwischen zwei Geräten getestet. Sie folgen der eigenen Hilfe von UU Remote. Das Relay auf einem Mac-Host wurde auf einem einzelnen Computer ausprobiert, einschließlich der Live-Verbindung des Browsers.
</Aside>

<strong>Browser auf deinem Computer</strong> → <strong>127.0.0.1 auf deinem Computer</strong> ⟷ UU Remote ⟷ <strong>127.0.0.1 auf dem Host</strong> → <strong>{productName}</strong>

<details>
<summary>Neu hier?</summary>

- <strong>127.0.0.1 (Loopback):</strong> eine Adresse, die immer „genau dieser Computer“ bedeutet.
- <strong>Port:</strong> eine Zahl, die ein Programm auf einem Computer auswählt, wie eine Türnummer. <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> ist Port {commands.defaultPort} auf diesem Computer.
- <strong>Portzuordnung (端口映射):</strong> eine Funktion von UU Remote, die einen Port auf dem Host als Port auf deinem eigenen Computer erscheinen lässt.
- <strong>socat:</strong> ein kleines, kostenloses Programm, das eine Verbindung von einem Ort an einen anderen weitergibt. Ein Mac-Host braucht es als Relay.
- <strong>Terminal:</strong> das Fenster, in das du Befehle eingibst: Terminal unter macOS, PowerShell unter Windows.

</details>

Die Portzuordnung von UU Remote lässt {productName} des Hosts auf deinem eigenen Computer unter <code dir="ltr">{tunnel.loopback}</code> erscheinen, der einzigen Adresse, unter der {productName} einen Browser annimmt.

## Bevor du anfängst

- <strong>Beide Computer sind ein Mac oder ein Windows-PC.</strong> UU Remote hat für Linux keine Portzuordnung; erreiche einen Linux-Server stattdessen über [Tailscale](../browser-over-tailscale/) oder [SSH](../remote-connections/).
- <strong>Auf beiden ist UU Remote installiert und beim selben Konto angemeldet,</strong> in Version 4.21.0 oder höher unter Windows und 4.32.0 oder höher unter macOS. Die Portzuordnung funktioniert nur für TCP, und mehr braucht {productName} nicht. Zum Zeitpunkt der Erstellung führt UU Remote die Portzuordnung unter seinen kostenlosen Funktionen auf; prüfe im Zweifel die aktuellen Tarife.
- <strong>Der Host erscheint unter „Meine Geräte“ (我的设备)</strong> in UU Remote auf dem Computer, von dem aus du im Browser arbeitest.
- <strong>Ein Mac-Host braucht außerdem [Homebrew](https://brew.sh/)</strong>, um unten socat zu installieren.

## Auf dem Computer, von dem aus du im Browser arbeitest

<Steps>

1. Öffne in UU Remote den Host unter <strong>Meine Geräte</strong> (我的设备), wähle auf seiner Karte <strong>Mehr</strong> (更多) und dann <strong>Portzuordnung</strong> (端口映射) und füge eine Zuordnung hinzu:

   | Feld | Wert |
   | --- | --- |
   | Name (名称) | {productName} |
   | Lokaler Port (本地端口) | <code dir="ltr">{commands.defaultPort}</code> |
   | Zieladresse (目标地址) | <code dir="ltr">127.0.0.1</code> |
   | Zielport (目标端口) | der Host-Port |

   Speichere und aktiviere sie und warte, bis sie als verbunden angezeigt wird. Wenn {commands.defaultPort} auf diesem Computer belegt ist, wähle einen anderen lokalen Port und ändere ihn auch in der Browser-Adresse.
2. Prüfe, dass nur dieser Computer die Zuordnung nutzen kann. Öffne auf diesem Computer das Terminal (macOS) oder PowerShell (Windows) und führe aus:

   <Tabs syncKey="visitor">
   <TabItem label="macOS">
   <Code code={tunnel.checkListener} lang="sh" />

   Du solltest eine Zeile sehen, die <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> und <code dir="ltr">LISTEN</code> enthält.
   </TabItem>
   <TabItem label="Windows">
   <Code code={tunnel.checkListenerWindows} lang="powershell" />

   Du solltest eine Zeile sehen, die mit <code dir="ltr">TCP</code> beginnt, dann <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> zeigt und mit <code dir="ltr">LISTENING</code> und einer Zahl endet.
   </TabItem>
   </Tabs>

   Wenn du stattdessen <code dir="ltr">*:{commands.defaultPort}</code> oder <code dir="ltr">0.0.0.0:{commands.defaultPort}</code> siehst, lösche die Zuordnung: Andere Geräte in deinem Netzwerk könnten {productName} erreichen.
3. Öffne die Browser-Adresse, die du auf dem Host kopiert hast. Sie beginnt mit <code dir="ltr">{tunnel.addressStart}</code>.

</Steps>

Es hat geklappt, wenn sich {productName} im Browser-Tab öffnet, ohne dass du dich anmelden musst.

## Wenn es nicht funktioniert

- <strong>Die Zuordnung wird als verbunden angezeigt, aber die Seite lädt nicht:</strong> Bei einem Mac-Host wurde das socat-Fenster geschlossen oder sein Befehl beendet; oder <strong>Fernzugriff erlauben</strong> ist ausgeschaltet, oder {productName} läuft auf dem Host nicht.
- <strong>Die Zuordnung lässt sich nicht speichern oder verbinden:</strong> Möglicherweise ist der lokale Port auf diesem Computer belegt. Wähle einen anderen und ändere ihn auch in der Browser-Adresse.
- <strong>Die Seite wird abgelehnt oder bleibt leer:</strong> Prüfe, ob du die Adresse unter <code dir="ltr">{tunnel.loopback}</code> geöffnet hast.

## Ausschalten

- <strong>Auf dem Computer, von dem aus du im Browser gearbeitet hast:</strong> Schalte die Zuordnung im Portzuordnungs-Bereich von UU Remote aus oder lösche sie. Auch das Schließen des Bereichs oder das Trennen beendet sie.
- <strong>Bei einem Mac-Host:</strong> Beende socat mit <kbd>Strg</kbd>+<kbd>C</kbd>.
- <strong>Schalte auf dem Host</strong> <strong>Fernzugriff erlauben</strong> aus, wenn du ihn nicht mehr brauchst. Das schließt den Browser-Zugang und trennt jede Seite, die mit dem Schlüssel geöffnet wurde.
- <strong>Wenn die Adresse möglicherweise durchgesickert ist,</strong> gib ihr mit <strong>Schlüssel erneuern</strong> auf dem Tab <strong>Browser</strong> einen neuen Schlüssel. Seiten, die mit der alten Adresse geöffnet sind, werden getrennt.

## Sicherheit

- <strong>Die Adresse ist das Passwort:</strong> Ihr Schlüssel gibt die volle Kontrolle über {productName} auf dem Host, einschließlich der Ausführung beliebiger Befehle. Er gilt, bis du ihn erneuerst. Er bleibt im Verlauf und in den Lesezeichen des Browsers und wird mit deinen anderen Geräten synchronisiert, wenn die Browser-Synchronisierung eingeschaltet ist.
- <strong>Wer sie erreichen kann:</strong> jeder, der den Host-Port erreicht und den Schlüssel hat. Auf dem Host lauscht er nur auf <code dir="ltr">127.0.0.1</code>; wer dein UU-Remote-Konto nutzen kann, um Ports zum Host zuzuordnen, kann ihn ebenfalls erreichen, daher halte dieses Konto sicher.
- <strong>Nur auf Computern, an denen sich sonst niemand anmeldet:</strong> Ein anderes Benutzerkonto auf dem Host oder auf deinem Computer kann sich mit diesen <code dir="ltr">127.0.0.1</code>-Ports verbinden, und solange die Zuordnung oder socat nicht läuft, kann es den Port übernehmen und den Schlüssel erhalten, wenn sich dein Browser neu verbindet. [Über SSH verbinden](../remote-connections/) hat bei einem Mac- oder Linux-Host diese Schwäche nicht, und auch dein eigener Computer hat sie nicht, wenn du die Desktop-App nutzt. Im Browser hat dein Computer sie weiterhin, denn dort lauscht die SSH-Weiterleitung ebenfalls auf einem <code dir="ltr">127.0.0.1</code>-Port.
