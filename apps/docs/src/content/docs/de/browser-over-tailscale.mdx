Öffne {productName} in einem Browser auf einem anderen Computer über dein eigenes Tailscale-Netzwerk, ohne SSH und ohne Remote-Desktop. Der Host ist der Computer, auf dem {productName} läuft: ein Mac, ein Windows-PC oder ein Linux-Server, auf dem octoboardd läuft. Die SSH-Anmeldung (Entfernte Anmeldung unter macOS) kann ausgeschaltet bleiben.

Du bist nicht sicher, ob das der richtige Weg für dich ist? Siehe [Verbindungsart wählen](../choose-how-to-connect/).

<Aside type="caution">
Diese Schritte wurden noch nicht vollständig getestet. Sie folgen der Dokumentation von Tailscale Serve und den eigenen Prüfungen von {productName}. Die Relay-Programme wurden auf einem einzelnen Computer ausprobiert, einschließlich der Live-Verbindung des Browsers; Tailscale Serve zwischen zwei Geräten und die Weiterleitung unter Windows wurden noch nicht ausprobiert.
</Aside>

<strong>Browser auf deinem Computer</strong> → <strong>Relay auf deinem Computer (127.0.0.1)</strong> ⟷ Tailscale ⟷ <strong>Relay auf dem Host (127.0.0.1)</strong> → <strong>{productName}</strong>

<details>
<summary>Neu hier?</summary>

- <strong>Tailscale:</strong> ein Dienst, der deine Geräte über das Internet zu einem privaten Netzwerk verbindet, egal wo sie stehen. Du meldest dich dort mit deinem eigenen Konto an.
- <strong>Tailnet:</strong> dein Tailscale-Netzwerk: die Geräte, die bei deinem Tailscale-Konto angemeldet sind.
- <strong>127.0.0.1 (Loopback):</strong> eine Adresse, die immer „genau dieser Computer“ bedeutet.
- <strong>Port:</strong> eine Zahl, die ein Programm auf einem Computer auswählt, wie eine Türnummer. <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> ist Port {commands.defaultPort} auf diesem Computer.
- <strong>socat:</strong> ein kleines, kostenloses Programm, das eine Verbindung von einem Ort an einen anderen weitergibt. Hier ist es das Relay.
- <strong>Tailscale Serve:</strong> ein Tailscale-Befehl, der einen Port nur für dein Tailnet freigibt. Sein Verwandter, Tailscale Funnel, würde ihn für das gesamte Internet freigeben; verwende ihn hier niemals.
- <strong>Terminal:</strong> das Fenster, in das du Befehle eingibst: Terminal unter macOS, PowerShell unter Windows.

</details>

## Warum die zusätzlichen Schritte

Aus Sicherheitsgründen nimmt {productName} nur einen Browser an, der es unter <code dir="ltr">{tunnel.loopback}</code> öffnet, einer Adresse, die immer „genau dieser Computer“ bedeutet (auch Loopback genannt). Du kannst also nicht einfach die Tailscale-Adresse des Hosts in den Browser eingeben. Stattdessen führst du auf jedem Computer ein kleines Relay-Programm aus: Auf deinem Computer lässt es den Host unter <code dir="ltr">{tunnel.loopback}</code> lokal erscheinen; auf dem Host übergibt es die Verbindung an {productName}. Tailscale transportiert den Datenverkehr zwischen den beiden.

## Bevor du anfängst

- <strong>Tailscale auf beiden Computern,</strong> angemeldet im selben Tailnet. Verwende ein Tailnet, das nur deine eigenen Geräte enthält: Jedes Gerät, das es zum Host durchlässt, kann den freigegebenen Port erreichen.
- <strong>socat auf jedem Computer, der ein Mac ist oder Linux nutzt.</strong> Ein Windows-Computer braucht es nicht.

## Wenn es nicht funktioniert

- <strong>Die Seite lädt nicht:</strong> Eines der Fenster wurde geschlossen, oder sein Befehl wurde beendet. Prüfe, ob die Relays und Tailscale Serve noch laufen und ob <code dir="ltr">{tunnel.serveStatus}</code> auf dem Host den Host-Port auflistet.
- <strong>socat meldet „Address already in use“:</strong> Dieser Port ist auf diesem Computer belegt. Wähle einen anderen Port; auf deinem Computer ändere ihn auch in der Browser-Adresse.
- <strong>Die Seite wird abgelehnt oder bleibt leer:</strong> Prüfe, ob du die Adresse unter <code dir="ltr">{tunnel.loopback}</code> geöffnet hast und nicht über den Tailscale-Namen des Hosts oder seine <code dir="ltr">100.x.y.z</code>-Adresse.
- <strong>Das Relay auf dem Host gibt „Connection refused“ oder „No such file or directory“ aus, wenn du die Seite öffnest:</strong> <strong>Fernzugriff erlauben</strong> ist ausgeschaltet, oder {productName} läuft auf dem Host nicht (unter Linux: octoboardd läuft nicht).

## Ausschalten

- <strong>Auf dem Computer, von dem aus du im Browser gearbeitet hast:</strong> Beende socat mit <kbd>Strg</kbd>+<kbd>C</kbd> oder lösche unter Windows die Weiterleitung in PowerShell, als Administrator ausgeführt:

  <Code code={tunnel.visitorForwardWindowsOff} lang="powershell" />
- <strong>Auf dem Host:</strong> Beende den Tailscale-Serve-Befehl und socat mit <kbd>Strg</kbd>+<kbd>C</kbd>. Prüfe mit <code dir="ltr">{tunnel.serveStatus}</code>, dass nichts mehr freigegeben ist; wenn der Port noch aufgelistet wird, entferne ihn mit <code dir="ltr">{tunnel.serveBridgeOff}</code> (unter Windows mit <code dir="ltr">{tunnel.serveBrowserPortOff}</code>).
- <strong>Bei einem Mac- oder Windows-Host</strong> schalte <strong>Fernzugriff erlauben</strong> aus, wenn du ihn nicht mehr brauchst. Das schließt den Browser-Zugang und trennt jede Seite, die mit dem Schlüssel geöffnet wurde.
- <strong>Wenn die Adresse möglicherweise durchgesickert ist,</strong> gib ihr mit <strong>Schlüssel erneuern</strong> auf dem Tab <strong>Browser</strong> einen neuen Schlüssel, oder unter Linux mit <code dir="ltr">{tunnel.rotate}</code>. Seiten, die mit der alten Adresse geöffnet sind, werden getrennt.

## Sicherheit

- <strong>Die Adresse ist das Passwort:</strong> Ihr Schlüssel gibt die volle Kontrolle über {productName} auf dem Host, einschließlich der Ausführung beliebiger Befehle. Er gilt, bis du ihn erneuerst. Er bleibt im Verlauf und in den Lesezeichen des Browsers und wird mit deinen anderen Geräten synchronisiert, wenn die Browser-Synchronisierung eingeschaltet ist.
- <strong>Wer sie erreichen kann:</strong> jeder, der den Host-Port erreicht und den Schlüssel hat. Die Relays lauschen nur auf <code dir="ltr">127.0.0.1</code>, daher können andere Geräte im Netzwerk des Hosts oder in deinem lokalen Netzwerk sie nicht erreichen; Tailscale Serve macht den Host-Port nur aus deinem Tailnet erreichbar, soweit dessen Zugriffsregeln es erlauben.
- <strong>Nur auf Computern, an denen sich sonst niemand anmeldet:</strong> Ein anderes Benutzerkonto auf dem Host oder auf deinem Computer kann sich mit diesen <code dir="ltr">127.0.0.1</code>-Ports verbinden, und solange ein Relay nicht läuft, kann es dessen Port übernehmen und den Schlüssel erhalten, wenn sich dein Browser neu verbindet. [Über SSH verbinden](../remote-connections/) hat bei einem Mac- oder Linux-Host diese Schwäche nicht, und auch dein eigener Computer hat sie nicht, wenn du die Desktop-App nutzt. Im Browser hat dein Computer sie weiterhin, denn dort lauscht die SSH-Weiterleitung ebenfalls auf einem <code dir="ltr">127.0.0.1</code>-Port.
- <strong>Niemals Funnel:</strong> Tailscale Funnel würde den Port für das gesamte Internet veröffentlichen.
