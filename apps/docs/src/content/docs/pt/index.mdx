O {productName} é um espaço de desenvolvimento local e de código aberto para agentes de programação. Ele reúne em um só lugar os agentes e as contas que você já tem: execute sessões lado a lado, troque de conta sem perder a conversa, passe tarefas de um provedor para outro e deixe um agente coordenador distribuir o trabalho entre vários projetos.

Um agente de programação é um assistente de IA que escreve e executa código para você, como o Claude Code ou o Codex. O {productName} não inclui nenhum: ele executa os que você já tem.

## Por onde começar

- **Usar o {productName} neste computador:** instale o app para [macOS](install/macos/) ou [Windows](install/windows/). É tudo de que a maioria das pessoas precisa.
- **Executar agentes em um servidor Linux** (uma máquina que você aluga ou mantém ligada em algum lugar, em geral sem tela): [instale o programa do servidor](install/linux/) e conecte-se a ele pelo app para desktop, como descreve [Conectar por SSH](remote-connections/).
- **Usar o {productName} de um computador a partir de outro:** comece por [Escolha como se conectar](choose-how-to-connect/), que compara as formas de acesso. Em resumo:
  - pelo app do outro computador, ou por um navegador, com o login SSH ativado: [Conectar por SSH](remote-connections/);
  - por um navegador, sem ativar o login SSH: [Navegador via Tailscale](browser-over-tailscale/) ou [Navegador via UU Remote](browser-over-uu-remote/).
