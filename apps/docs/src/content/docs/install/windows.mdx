For PCs with an Intel or AMD processor (x64; almost all Windows PCs), on Windows 10 version 21H2 or later. On Windows 11 on Arm, use the native arm64 installer where the release offers one; otherwise this x64 app runs there under emulation.

## Install

<Steps>

1. Download the installer with the button above. It's a file whose name ends in <code dir="ltr">x64-setup.exe</code>. On Windows on Arm, try the second button: where the release offers an arm64 installer, it downloads that file, whose name ends in <code dir="ltr">arm64-setup.exe</code>; otherwise it opens the list of releases, and the x64 installer runs under emulation.
2. Open the downloaded file to run the installer. It installs {productName} for your user account only, so it doesn't ask for an administrator.

   The app is not code-signed yet, so Microsoft Defender SmartScreen may show “Windows protected your PC”. Select “More info”, then “Run anyway”.

   If your PC lacks Microsoft Edge WebView2, which draws the app's window, the installer downloads it, so stay connected to the internet.
3. Open {productName} from the Start menu.
4. Install at least one coding agent (see below), then select <strong>Add project</strong> in {productName} to open a project folder.

</Steps>

When the main window opens, you're done.

## Install a coding agent

{productName} doesn't include an AI agent. Install the ones you want to use by following their own instructions, and sign in to them. {productName} finds them automatically. It works with:

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)

If you use Claude Code or Codex, install [Git for Windows](https://git-scm.com/download/win) first; they need it to work.

## Uninstall

Uninstall {productName} with its uninstaller, from Windows' Settings (Apps) or Control Panel.

<WindowsUninstaller />

To see what is in effect before you uninstall, open <strong>Settings › Cleanup › Clean up before uninstalling</strong>: <strong>Remove all</strong> there removes the same, and shows the result for each item.

[Your system stays as it was](../../your-system/) says what is left afterwards and how to remove it.
