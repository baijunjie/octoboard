## Install

<Steps>

1. Download the app with the button above. You get a disk image, a file whose name ends in <code dir="ltr">.dmg</code>.
2. Open the downloaded file. In the window that opens, drag {productName} onto the Applications folder.
3. Open {productName} from your Applications folder or from Launchpad.
4. Install at least one coding agent (see below), then select <strong>Add project</strong> in {productName} to open a project folder.

</Steps>

When the main window opens, you're done.

## Install a coding agent

{productName} doesn't include an AI agent. Install the ones you want to use by following their own instructions, and sign in to them. {productName} finds them automatically. It works with:

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)
- [Antigravity CLI](https://antigravity.google/product/antigravity-cli)
- [GitHub Copilot CLI](https://github.com/github/copilot-cli)
- [OpenCode](https://opencode.ai)
- [Qwen Code](https://github.com/QwenLM/qwen-code)
- [Pi](https://github.com/earendil-works/pi)

## Uninstall

Before you uninstall, open <strong>Settings › Cleanup › Clean up before uninstalling</strong> and select <strong>Remove all</strong>. It removes what the features you turned on added outside {productName}'s own folders, which deleting the app does not remove: nothing runs when it is deleted. Then quit {productName} and delete it from your Applications folder.

[Your system stays as it was](../../your-system/) says what is left afterwards and how to remove it.
