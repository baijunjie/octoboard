<LinkButton href={downloads.macos}>Tải xuống cho macOS</LinkButton>

## Cài đặt

<Steps>

1. Tải ứng dụng bằng nút ở trên. Bạn nhận được một ảnh đĩa, là tệp có tên kết thúc bằng <code dir="ltr">.dmg</code>.
2. Mở tệp vừa tải. Trong cửa sổ hiện ra, kéo {productName} vào thư mục Applications.
3. Mở {productName} từ thư mục Applications hoặc từ Launchpad.
4. Cài ít nhất một tác tử lập trình (xem bên dưới), rồi chọn <strong>Thêm dự án</strong> trong {productName} để mở một thư mục dự án.

</Steps>

Khi cửa sổ chính mở ra là bạn đã cài xong.
