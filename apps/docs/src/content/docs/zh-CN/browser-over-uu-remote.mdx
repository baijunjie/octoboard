通过网易 [UU 远程](https://uuyc.163.com/)的端口映射，在另一台电脑的浏览器中打开 {productName}，无需 SSH 或远程桌面。主机是运行 {productName} 的那台电脑（即 UU 远程里的“被控端”）；SSH 登录（macOS 上的“远程登录”）可以保持关闭，也不需要远程桌面会话。用来浏览的电脑称为访问端（即 UU 远程里的“主控端”）。

本页介绍的是在自己电脑的浏览器中打开 {productName}，这种方式比远程桌面清晰流畅，但步骤更多。如果不介意延迟和模糊，直接用 UU 远程的远程桌面在主机上操作即可。

不确定该用哪种方式？请看[选择连接方式](../choose-how-to-connect/)。

<Aside type="caution">
这些步骤尚未在两台设备之间实测，依据 UU 远程自己的帮助编写。
</Aside>

<strong>你电脑上的浏览器</strong> → <strong>你电脑上的 127.0.0.1</strong> ⟷ UU 远程 ⟷ <strong>主机上的 127.0.0.1</strong> → <strong>{productName}</strong>

<details>
<summary>新手须知</summary>

- <strong>127.0.0.1（回环地址）：</strong>永远指“本机”的地址。
- <strong>端口：</strong>用来指定电脑上某个程序的编号，就像门牌号。<code dir="ltr">127.0.0.1:{commands.defaultPort}</code> 就是本机的 {commands.defaultPort} 端口。
- <strong>端口映射：</strong>UU 远程的一项功能，让主机上的某个端口出现在你自己的电脑上。
- <strong>终端：</strong>输入命令的窗口，macOS 上是“终端”，Windows 上是 PowerShell。

</details>

UU 远程的端口映射会让主机上的 {productName} 出现在你自己电脑的 <code dir="ltr">{tunnel.loopback}</code> 上，而 {productName} 只接受这个地址上的浏览器访问。

## 准备工作

- <strong>两台电脑都是 Mac 或 Windows 电脑。</strong>UU 远程没有 Linux 版端口映射；请改用 [Tailscale](../browser-over-tailscale/) 或 [SSH](../remote-connections/) 访问 Linux 服务器。
- <strong>两台电脑都装好 UU 远程，并登录同一个账号，</strong>Windows 上需要 4.21.0 及以上版本，macOS 上需要 4.32.0 及以上版本。端口映射只支持 TCP，{productName} 也只需要 TCP。撰写本文时，UU 远程把端口映射列为免费功能；如有疑问，请查看它当前的会员说明。
- <strong>访问端的 UU 远程里，“我的设备”中能看到这台主机。</strong>

## 在主机上

<Steps>

1. 获取浏览器地址，地址里带有登录密钥，用浏览器打开即可直接登录。

   <HostBrowserAddress />
2. 在主机上准备一个能连到 {productName} 的本机端口。下文的<strong>主机端口</strong>就是这个端口。

   无需运行任何命令：{productName} 自己就在浏览器端口上监听，而且只监听 <code dir="ltr">127.0.0.1</code>。主机端口就是<strong>设置 › 访问</strong>里的<strong>浏览器端口</strong>（没改过的话是 {commands.defaultPort}）。

</Steps>

## 在访问端电脑上

<Steps>

1. 在 UU 远程中，从<strong>我的设备</strong>打开主机，点击设备卡片上的<strong>更多</strong>，选择<strong>端口映射</strong>，然后新建一条映射：

   | 字段 | 值 |
   | --- | --- |
   | 名称 | {productName} |
   | 本地端口 | <code dir="ltr">{commands.defaultPort}</code> |
   | 目标地址 | <code dir="ltr">127.0.0.1</code> |
   | 目标端口 | 主机端口 |

   保存并启用，等它显示已连接。如果这台电脑上的 {commands.defaultPort} 端口已被占用，请换一个本地端口，并在浏览器地址中也改成它。
2. 确认只有这台电脑能用这条映射。在这台电脑上打开“终端”（macOS）或 PowerShell（Windows），运行：

   <Tabs syncKey="visitor">
   <TabItem label="macOS">
   <Code code={tunnel.checkListener} lang="sh" />

   输出中应该有一行同时包含 <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> 和 <code dir="ltr">LISTEN</code>。
   </TabItem>
   <TabItem label="Windows">
   <Code code={tunnel.checkListenerWindows} lang="powershell" />

   输出中应该有一行以 <code dir="ltr">TCP</code> 开头、接着是 <code dir="ltr">127.0.0.1:{commands.defaultPort}</code>，并以 <code dir="ltr">LISTENING</code> 和一个数字结尾。
   </TabItem>
   </Tabs>

   如果那个位置显示的是 <code dir="ltr">*:{commands.defaultPort}</code> 或 <code dir="ltr">0.0.0.0:{commands.defaultPort}</code>，请删除这条映射：你网络中的其他设备也能访问 {productName}。
3. 打开在主机上复制的浏览器地址。它以 <code dir="ltr">{tunnel.addressStart}</code> 开头。

</Steps>

看到 {productName} 在浏览器标签页中打开，而且没有要求你登录，就说明成功了。

## 连不上时

- <strong>映射显示已连接，但页面打不开：</strong><strong>允许浏览器访问</strong>没有开启，或主机上的 {productName} 没有运行。
- <strong>映射无法保存或连不上：</strong>这台电脑上的本地端口可能已被占用。请换一个，并在浏览器地址中也改成它。
- <strong>页面被拒绝或一片空白：</strong>请确认打开的是 <code dir="ltr">{tunnel.loopback}</code> 开头的地址。

## 停止使用

- <strong>在访问端电脑上：</strong>在 UU 远程的端口映射面板中停用或删除这条映射。关闭面板或断开连接也会让映射停止。
- <strong>在主机上，</strong>不再需要时请关闭<strong>允许浏览器访问</strong>。这会关闭浏览器端口，并断开所有用该密钥打开的页面。
- <strong>如果地址可能已泄露，</strong>在<strong>设置 › 访问</strong>点击<strong>轮换密钥</strong>给它换一个新密钥。用旧地址打开的页面会被断开。

## 安全

- <strong>地址就是密码：</strong>地址里的密钥可以完全控制主机上的 {productName}，包括运行任何命令。密钥在你轮换之前一直有效。它会留在浏览器的历史记录和书签里，开启同步后还会同步到你的其他设备。
- <strong>谁能访问：</strong>能访问主机端口并持有密钥的任何人。主机上的端口只监听 <code dir="ltr">127.0.0.1</code>；能用你的 UU 远程账号向这台主机映射端口的人也能访问它，请保管好这个账号。
- <strong>只在没有其他人登录的电脑上使用：</strong>主机或你电脑上的其他用户账户可以连接这些 <code dir="ltr">127.0.0.1</code> 端口；{productName} 没在运行或正在重启时，他们还可以占用主机上的浏览器端口；你电脑上的映射没在运行时，则可以占用它映射的端口；在你的浏览器重连时拿到密钥。[通过 SSH 连接](../remote-connections/)时，关闭了浏览器访问的 Linux 主机、以及从桌面应用使用的 Mac 或 Windows 主机，都没有这个弱点；用桌面应用时，你自己的电脑也没有。但用浏览器时，你用来浏览的电脑仍有这个弱点，因为那里的 SSH 转发同样监听 <code dir="ltr">127.0.0.1</code> 端口。
