智能体会启动开发服务器和监视进程，会话结束后它们常常被遗忘，白白占着内存和端口。{productName} 实时列出这些进程及其内存、端口和本地链接，并在会话结束时尝试清理；想留着的，可以保留。

<Screenshot id="processes-of-session" alt="会话的“进程”面板，四张卡片各显示一条命令、它的文件夹和内存，两个服务器上还有网页链接。" />

## 功能说明

- <strong>进程属于拉起它的那次会话启动。</strong>无论进程是怎么启动的、后来又转移到了哪里，它属于某次会话启动，都是因为它的父进程链通向智能体，或者它的环境里带有这次启动的标记，或者它运行在这次启动的某个进程创建的终端会话里。它脱离或转移之后仍然属于这次启动。
- <strong>会话启动的东西随会话结束。</strong>智能体的进程结束时，无论原因是什么（自行退出、你归档了会话、应用退出），{productName} 都会停止它认定属于这次启动的进程，你选择保留的除外。在 macOS 和 Linux 上，它先请这些进程退出，3 秒后强制结束仍未退出的。
- <strong>“保留”是你让某个进程幸免的办法。</strong>保留的进程不再随会话停止。它会移到项目自己的列表里，不会自动停止，直到你来停止它。
- <strong>交接或重启不算结束。</strong>切换会话的账户、更换模型和交接会话，都会把正在运行的进程带给接替它的会话。已保留的进程保持保留。
- <strong>你在它们运行的地方就能看到。</strong>左侧栏会统计所有项目和控制台会话的进程树。项目的进程面板会列出它们，显示每个进程的命令、文件夹、内存、监听端口，以及每个提供网页的端口的链接。
- <strong>会话不会因应用自己的重启而消失。</strong>每个会话的终端都在一个独立的托管进程下运行，所以有计划的重启（比如为了更新）会把会话交接过去，而不是结束它们。普通的退出会结束会话和它们启动的进程，你保留的除外。

<Aside type="caution" title="局限">
- 有些进程无法保留：在 Windows 主机上，是挂在智能体自己终端上的进程；在 macOS 和 Linux 上，是在智能体仍在运行的命令里的进程。它们的<strong>保留</strong>不可用，原因显示在提示里。
- 有些进程无法归属：macOS 不提供其环境的系统程序，如果由一条约 2 秒内就退出的命令放到后台启动，既不会被列出，也不会被停止。
- Claude Code 退出时会结束它启动的后台 shell，所以用这种方式启动的服务器撑不过交接或重启；智能体以分离方式启动的则可以。
- 停止可能被拒绝：系统可能不允许停止其他用户的进程，也可能有进程被杀掉后仍然存在。这棵进程树会继续列出，并有提示说明原因。
- 网页链接是 <code dir="ltr">{commands.localhost}</code> 地址，所以在守护进程运行的那台电脑上打开。在远程窗口里，{productName} 会通过转发的端口访问它们。
</Aside>

## 为什么这样设计

- <strong>归属取决于进程是怎么启动的，而不是它看起来像什么。</strong>这不依赖智能体报告后台任务，也不依赖它记得清理。{productName} 没有“该保留”或“该停止”的程序名单，也不去判断一个进程是什么，所以智能体拉起的共享服务（比如构建守护进程）也会随会话停止，即使之后有别的程序开始使用它。

## 如何使用

<Steps>

1. 只要有进程在运行，左侧栏就会出现带绿色数字的<strong>进程</strong>按钮。把鼠标放在它上面，或按回车，可以看到进程在哪里运行，按<strong>控制台会话</strong>和<strong>项目</strong>分组。
2. 选择一行。右侧窗格会切换到该项目或控制台会话的<strong>进程</strong>面板。你也可以用顶栏的<strong>显示进程面板</strong>打开它。
3. 看卡片。<strong>会话进程</strong>下按启动它们的会话分组；<strong>项目进程</strong>下是不属于任何会话的进程。选择卡片上的网页链接，可以在浏览器里打开那个服务器。<strong>按会话筛选</strong>可以把列表缩小到一个会话。
4. 想立刻结束某个进程，把鼠标放在它的卡片上（或把焦点移上去），选择<strong>停止</strong>，并在<strong>停止进程</strong>对话框里确认。
5. 想让某个进程比它的会话活得更久，选择<strong>保留</strong>，并在<strong>保留进程</strong>里确认。它会移到<strong>项目进程</strong>。只有项目会话的进程可以保留：控制台会话的卡片只有<strong>停止</strong>。

</Steps>


<Screenshot id="processes-on-rail" alt="左侧栏的“进程”弹出面板，按控制台会话和项目列出正在运行的进程。" />

出现提示说进程已停止或已保留，并且它的卡片离开或移到另一个列表，就说明成功了。归档会话时如果有进程仍在运行，归档确认会把它们列出来，并让你取消勾选想保留的进程。
