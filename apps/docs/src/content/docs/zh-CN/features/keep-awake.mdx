你离开后智能体还在工作，但睡着的电脑不会。{productName} 可以让电脑保持唤醒，也让显示器不关闭、不锁屏，这样不需要人守在键盘前的工作就能继续。对于需要智能体在人不在时做、又依赖有画面的工作，比如截图或操作浏览器，这一点尤其有用。

<Screenshot id="prevent-sleep-setting" alt="设置中的“通用”页面，“阻止睡眠”已开启，“何时阻止睡眠”为“会话工作期间”。" />

## 为什么这样设计

- <strong>智能体的工作不该取决于你是否守在电脑前。</strong>开启<strong>阻止睡眠</strong>后，{productName} 会挡住因闲置而触发的睡眠，长时间的运行不会被系统的闲置计时器打断，需要画面的工作屏幕也会一直亮着。
- <strong>被保持唤醒的是主机。</strong>这台电脑指运行守护进程（{productName} 的后台程序）的那一台。你在一台电脑上使用 {productName}、守护进程在另一台上时，保持唤醒的是另一台，而不是你面前这台。
- <strong>默认关闭，何时生效由你选。</strong><strong>何时阻止睡眠</strong>有两个选项：默认的<strong>会话工作期间</strong>，以及<strong>始终</strong>。<strong>会话工作期间</strong>会在有会话正在启动、工作、休眠或在后台工作时保持唤醒；在等你的会话不算，没有会话算数时，系统自己的设置重新生效。<strong>始终</strong>则在守护进程运行期间一直保持；在桌面应用里，就是应用运行期间，无论窗口是显示还是收进后台。
- <strong>具体挡住什么，取决于系统。</strong>
  - macOS：显示器和系统都不会因闲置而睡眠，所以你闲置时屏幕既不会熄灭，也不会锁定。
  - Windows：同时请求保持显示器和系统唤醒。显示器这部分是尽力而为：在没有显示器的会话里（比如服务或 SSH 会话），只保持系统唤醒。
  - Linux：通过 logind（系统的会话服务）保持系统唤醒。{productName} 还会请桌面的屏幕保护服务暂时不动作，在桌面遵守这一请求时，桌面自己的熄屏、锁屏和自动挂起就不会触发。这一部分是尽力而为。

<Aside type="caution" title="局限">
- 只挡住因闲置而触发的睡眠。合上笔记本盖子，或手动让电脑睡眠，电脑仍然会睡眠。
- 只有主机能被保持唤醒时才会出现这个设置：macOS 和 Windows 始终可以，Linux 只有在 logind 在系统总线上有响应时才可以。其他情况下不显示这些设置行。
- 主机拒绝保持唤醒时，什么都不会被保持，守护进程会记录原因。
- {productName} 退出，或守护进程停止、崩溃时，保持唤醒随之结束。
</Aside>

## 如何使用

<Steps>

1. 打开<strong>设置 › 通用</strong>，找到<strong>电源</strong>分组。如果没有这个分组，说明运行守护进程的电脑无法被保持唤醒。
2. 打开<strong>阻止睡眠</strong>。开关一切换就会保存。
3. 在它下面选择<strong>何时阻止睡眠</strong>：想只在智能体忙的时候保持唤醒，选<strong>会话工作期间</strong>；想在守护进程运行期间（桌面应用里即应用运行期间，窗口显示或收起都算）一直保持，选<strong>始终</strong>。
4. 让智能体继续工作，然后离开。想确认已经生效，可以看桌面应用的菜单栏图标（Windows 上为通知区域图标）：{productName} 在让电脑保持唤醒时，图标的眼睛会变红。

</Steps>

会话工作、你闲置期间，电脑和显示器保持唤醒，就说明成功了。关闭<strong>阻止睡眠</strong>后，系统自己的设置会立即重新生效。
