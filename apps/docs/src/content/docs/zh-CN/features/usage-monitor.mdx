## 功能说明

- <strong>窗口的名称沿用智能体自己的叫法。</strong>Claude Code 把 5 小时窗口叫<strong>会话</strong>，整个账户的每周窗口叫<strong>每周</strong>（当某个模型另有自己的每周限额时，叫<strong>每周 · 所有模型</strong>），有自己限额的每个模型各有一个以模型命名的每周窗口。Codex 显示<strong>5 小时</strong>和<strong>每周</strong>。Grok Build 显示一个额度池，按周期叫<strong>每周</strong>、<strong>每月</strong>或<strong>额度</strong>。每个窗口都显示剩余的百分比、一根进度条和“多久后重置”的倒计时。
- <strong>读取结果会自动刷新。</strong>每个账户大约每 5 分钟读取一次；窗口重置后不久会再读一次；添加账户或账户登录后不久也会读；打开<strong>设置 › 智能体账户</strong>、用量面板或菜单栏菜单时，也会读取最近没有读过的账户。读取失败后，重试的间隔会越来越长，最长 40 分钟。
- <strong>拿不准时会告诉你。</strong>每个账户都会显示读取的时间距今多久。如果最近一次读取失败，会保留上一次成功的结果，并标为已过期，原因在弹出的说明里。未登录的账户会如实显示为未登录。
- <strong>局限：</strong>它只显示套餐和各个窗口，不显示花费、余额或预测。读取结果只保存在内存里，也不会导出，所以重启之后每个账户都要等第一次读取才有数据。已停用的账户不会被读取；使用 API 密钥或其他没有套餐额度的提供方的账户，没有用量可显示。

## 为什么这样设计

- <strong>直接问智能体本身。</strong>对每个账户，{productName} 在账户的文件夹里运行智能体自带的用量查询命令，并显示得到的结果，所以它不使用自己的凭据，也不连接自己的服务。

## 如何使用

<Steps>

1. 把鼠标放在左侧栏中设置上方的<strong>账户用量</strong>按钮（仪表图标）上。会弹出一个面板，每个智能体一个标签页，下面是该智能体的账户，各自显示套餐、剩余用量和倒计时。按 Enter 或空格键可以用键盘打开。
2. 选中某个会话时，这个按钮上还会有一个紧凑的指示条，位于仪表下方，显示该会话所用账户各个窗口还剩多少。
3. 想看某个账户的完整情况，打开<strong>设置 › 智能体账户</strong>。<strong>用量</strong>列为每个账户显示一根紧凑的进度条；在账户的操作菜单中选择<strong>详情</strong>，可以看到所有窗口，包括某个模型自己的每周限额。
4. 在 macOS 和 Windows 上，菜单栏或通知区域里的章鱼图标会为所选会话显示同样的指示条，它的菜单里为每个智能体各有一个用量子菜单。

</Steps>

<Screenshot id="account-details-usage" alt="“账户详情”对话框，显示账户的套餐、文件夹和各用量窗口。" />

阅读时需要知道的几点：

- 已用完某个窗口的账户会显示<strong>已达上限</strong>，进度条变成灰色。这指的是 5 小时、每周或额度池窗口用完；只有某个模型自己的每周限额用完，不算在内。
- 已经重置但尚未开始计时的窗口不显示倒计时。如果希望 {productName} 去启动它，请在<strong>设置 › 智能体账户</strong>中开启<strong>自动启动用量窗口</strong>。
- 持有使用限制重置次数的 Codex 账户会显示次数，并附有<strong>兑换重置</strong>按钮。
- 默认账户显示为你给它起的名字，没起过就显示<strong>默认</strong>。
- 已停用的账户不会出现在面板里，除非所选会话正运行在它上面。

<Aside type="note">
面板只负责报告。新会话仍然可以在已达上限的账户上打开，它会停在那里直到重置；被拒绝的是把会话切换或移交到这样的账户上。
</Aside>
