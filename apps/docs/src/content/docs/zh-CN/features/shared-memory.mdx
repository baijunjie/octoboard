每个智能体都有自己的记忆，按智能体和账户分开，所以换了智能体或账户的会话，看不到之前的会话学到的东西。{productName} 有一份所有智能体共享的记忆：会话把值得留下的内容记下来，之后的会话一开始就知道，无论它们用的是哪个智能体或账户。你随时可以查看和修正。

## 为什么这样设计

- <strong>一个会话学到的东西，应该帮到下一个，不论用哪个智能体。</strong>记忆有两种。控制台的记忆由这个控制台的所有控制台会话读写：你的偏好和纠正、哪类请求归哪个项目、不涉及任何项目的工作所需的机器信息。项目的记忆由在这个项目里工作的所有会话读写：智能体需要知道的项目所在机器的信息，例如本机路径、端口，以及本机工具在那里的表现。项目的其他知识，应该写进项目自己的文档。
- <strong>它默认关闭，由你来开启。</strong><strong>设置 › 记忆</strong>里的<strong>让会话共享 {productName} 的记忆</strong>默认关闭。关闭时，会话的表现就像没有记忆一样。之后再关闭，不会删除任何内容。
- <strong>会话一开始拿到的是索引，需要时再打开条目。</strong>每个条目有一句话的摘要，新会话拿到的是按最近更新排序的摘要列表，只有当某条摘要与手头的工作相关时，才会读它的全文。会话保存时不会问你，控制台会话还会在回复里说明保存了什么，方便你纠正。
- <strong>智能体自带的记忆会被关闭，所以不会学两遍。</strong>共享记忆开启时，{productName} 启动的每个会话，在这次启动里都会关闭它的智能体自带的记忆，让它把学到的东西记在共享记忆里。不会往智能体的配置里写任何东西，智能体之前写下的内容也保持原样。
- <strong>条目是你读得懂的短笔记。</strong>它由最多 200 个字符的摘要和最多 16,384 字节的 Markdown 内容组成，并记录最后更新的时间和更新者：你，或某个智能体，例如 Codex。一份记忆最多有 200 个条目。
- <strong>没人会覆盖自己没见过的修改。</strong>修改某个条目的保存，如果在读取之后条目已被别人保存过，就会被拒绝，不会丢失任何内容：会话或你的表单会拿到当前的条目，合并后再保存。
- <strong>项目的记忆属于文件夹，而不是项目本身。</strong>同一台电脑上同一位置的所有项目共享它；移除项目会保留它的记忆，除非你在移除确认里勾选了<strong>同时删除此项目的记忆</strong>，所以在同一文件夹重新添加项目，就能再次找到它。

<Aside type="caution" title="局限">
- 这个设置只对你修改之后启动的会话生效。已经在运行的会话保持它启动时的状态。
- 会话的索引是它启动时的快照；它可以请求当前的索引，其中包含其他会话此后保存的内容。
- 记忆是背景信息，不是指令：它的优先级低于你的指示、项目自己的约定和你在对话中说的话，会话在依赖它之前会先核对。
- 控制台记忆里的条目可以标记为<strong>仅限本机</strong>，表示只对运行守护进程（{productName} 的后台程序）的那台电脑有效。配置导出会带上控制台的记忆，但不含这些条目，也从不带上项目的记忆或这个设置本身。
- 删除控制台会同时删除它的记忆。
</Aside>

## 如何使用

<Steps>

1. 打开<strong>设置 › 记忆</strong>，开启<strong>让会话共享 {productName} 的记忆</strong>。此后你启动的会话会读取并保存这份记忆。
2. 打开控制台的操作菜单并选择<strong>记忆</strong>，或打开项目的操作菜单并选择<strong>记忆</strong>。对话框的标题是<strong>控制台记忆</strong>或<strong>项目记忆</strong>，它的条目是它的会话保存的内容，以及你自己添加的内容。只有设置开启时才有这个菜单项。
3. 选择一行，可以读条目的全文。该行的菜单有<strong>查看</strong>、<strong>编辑</strong>和<strong>删除</strong>。
4. 想自己添加一条，选择<strong>添加条目</strong>，填写<strong>摘要</strong>和<strong>内容</strong>。控制台的表单还有<strong>仅限本机</strong>复选框。
5. 想清空一份记忆，选择<strong>全部删除</strong>，并按对话框的要求输入那个词来确认。

</Steps>

<Screenshot id="memory-entry-edit" alt="“编辑记忆条目”对话框，已填写“摘要”和“内容”，并勾选了“仅限本机”。" />

会话保存的条目不用重新打开对话框就出现在里面，而你添加的条目显示<strong>你刚刚更新</strong>，就说明成功了。

项目被移除后，它的记忆会保留，除非你在移除确认里勾选了<strong>同时删除此项目的记忆</strong>。在<strong>设置 › 记忆</strong>的<strong>已移除项目的记忆</strong>里，<strong>管理</strong>会列出每个遗留了记忆的文件夹，以及它所在的设备、条目数和最后更新的时间，并可以删除某个文件夹的记忆或全部删除。
