同时跑很多会话时，最大的成本是不知道哪个在等你。{productName} 让状态一眼可见，会话等你时会通知你；点进去就能直接在终端里回答或调整指令。编排不等于放任，你随时可以接手。

## 功能说明

- <strong>状态来自智能体自己的报告。</strong>{productName} 根据 Claude Code、Codex、Grok Build、Antigravity CLI、GitHub Copilot CLI、OpenCode、Qwen Code 和 Pi 的钩子与事件，判断轮次何时开始、何时等待输入、何时结束。有些情形智能体什么也不报告，{productName} 就读它的终端，比如 Codex 需要你时显示的标题。
- <strong>颜色表示会话对你有什么要求。</strong>橙色表示它需要你（<strong>等你回应</strong>、<strong>已休眠</strong>）；绿色表示它停在提示符处，可以和它对话（<strong>已暂停</strong>、<strong>已完成</strong>、<strong>等待指示</strong>、<strong>子会话工作中</strong>、<strong>后台工作中</strong>）；蓝色表示它正忙（<strong>工作中</strong>）；灰色表示现在无法和它对话（<strong>启动中</strong>、<strong>账户切换中</strong>、<strong>正在重连</strong>、<strong>已中断</strong>）。<strong>状态未知</strong>是虚线空心圆，表示一个本窗口不认识的状态。
- <strong>等待中的会话容易找到。</strong>它那一行会显示一只举起的手；它所在的项目折叠起来时也会显示，它所属控制台在左侧栏上的头像也会显示。会话开始等待时，{productName} 还会弹出一次系统通知。
- <strong>介入就是输入。</strong>会话的终端是实时的：按键直接发给智能体，和普通终端一样。你在提问的地方回答权限提示或问题，也可以通过给运行中的会话发一条消息来调整它的要求，无论这个会话是你启动的还是控制台会话启动的。
- <strong>中断一轮工作要按智能体自己的中断键。</strong>窗口里没有停止按钮；在会话的终端里按这个键即可。会话保留它的进程和对话，状态变为<strong>已暂停</strong>，等你的下一条消息。控制台会话，或启动过其他会话的会话，也能用同样的方式中断它名下的会话。这和<strong>已中断</strong>不同：<strong>已中断</strong>表示会话的进程已经结束，选中这样的会话那一行就会恢复它。

<Aside type="caution" title="局限">
- 一轮工作以智能体用普通文字提问结束时，{productName} 会将其视作正常结束，所以这个会话会显示为<strong>已完成</strong>，而不是<strong>等你回应</strong>。
- Codex 没有信号表明它通过自带的“向用户提问”工具提了问题；这样的会话显示为<strong>工作中</strong>，除非 Codex 的标题表明它需要你。
- <strong>后台工作中</strong>适用于 Claude Code、Grok Build、Antigravity CLI、GitHub Copilot CLI 和 Qwen Code。
- {productName} 暂时连不上进程的会话显示为<strong>正在重连</strong>，重新连上之前不计入等待。
- 在 macOS 上，{productName} 位于最前时可能不会出现通知横幅。
</Aside>

## 如何使用

<Steps>

1. 看侧边栏里会话那一行的状态图标。折叠的项目显示的是它最紧急的会话的图标，所以你可以让项目保持折叠。把鼠标放在图标上，可以看到文字说明的状态。
2. 找到在等你的会话。左侧栏底部举起的手会统计在等待的会话数；点它就选中下一个，再点就到再下一个。你也可以选中左侧栏上某个控制台的头像，它带有一个角标，表示该控制台最紧急的会话。
3. 介入。选中会话后，它的终端就在你面前：回答问题或权限提示，或者输入新的指示。
4. 想停下一轮工作，在它的终端里按智能体的中断键。那一行会变成<strong>已暂停</strong>。
5. 想把某个项目或某个控制台会话的会话以卡片形式查看，在项目菜单或会话菜单里选择<strong>专注模式</strong>。选择<strong>退出专注模式</strong>即可返回。

</Steps>


<Screenshot id="focus-mode-sessions" alt="“专注模式”把一个项目的会话列成卡片，每张卡片带有状态。" />

你回答过的会话从<strong>等你回应</strong>变成<strong>工作中</strong>，左侧栏上的计数也减少了，就说明成功了。你批准某个权限后，会话会一直显示为<strong>等你回应</strong>，直到你允许的那条命令运行完。

### 相关设置

- 在<strong>设置 › 通知</strong>里有系统通知的设置。在 macOS 和 Windows 上，通知由系统自己的设置管理，这一行有一个按钮可以打开它们。
- 在 macOS 上，菜单栏图标会列出等你回应、已暂停、已完成或等待指示的会话，并在有会话等待或休眠时显示橙色圆点。在 Windows 上，通知区域图标会打开一个带有同样列表的浮窗。
- <strong>设置 › 智能体行为</strong>里的<strong>自动批准新建会话请求</strong>等开关，决定会话的哪些请求要等你回答。
