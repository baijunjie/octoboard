适用于 Intel 或 AMD 处理器的电脑（x64，绝大多数 Windows 电脑），需要 Windows 10 版本 21H2 或更高版本。在 Arm 版 Windows 11 上，发布版本提供原生 arm64 安装程序时请使用它；否则这个 x64 应用会以仿真方式运行。

## 安装

<Steps>

1. 点击上面的按钮下载安装程序，文件名以 <code dir="ltr">x64-setup.exe</code> 结尾。Arm 版 Windows 请试试第二个按钮：发布版本提供 arm64 安装程序时，它会下载文件名以 <code dir="ltr">arm64-setup.exe</code> 结尾的那个文件；否则会打开发布版本列表，x64 安装程序以仿真方式运行。
2. 打开下载的文件，运行安装程序。它只为你当前的用户账号安装 {productName}，不需要管理员权限。

   应用尚未进行代码签名，因此 Microsoft Defender SmartScreen 可能显示“Windows 已保护你的电脑”。请点击“更多信息”，再点击“仍要运行”。

   应用窗口由 Microsoft Edge WebView2 绘制。电脑上没有 WebView2 时，安装程序会下载它，所以请保持联网。
3. 从“开始”菜单打开 {productName}。
4. 安装至少一个编程智能体（见下文），然后在 {productName} 中点击<strong>添加项目</strong>，打开一个项目文件夹。

</Steps>

看到主窗口打开，就安装完成了。

## 安装编程智能体

{productName} 本身不带 AI 智能体，请按各自的官方说明安装并登录你要用的智能体，{productName} 会自动识别。目前支持：

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)
- [Antigravity CLI](https://antigravity.google/product/antigravity-cli)
- [GitHub Copilot CLI](https://github.com/github/copilot-cli)
- [OpenCode](https://opencode.ai)
- [Qwen Code](https://github.com/QwenLM/qwen-code)
- [Pi](https://github.com/earendil-works/pi)

如果你使用 Claude Code 或 Codex，请先安装 [Git for Windows](https://git-scm.com/download/win)，它们需要它才能工作。

## 卸载

从 Windows 设置（应用）或控制面板中，用 {productName} 的卸载程序卸载它。
