通过你自己的 Tailscale 网络，在另一台电脑的浏览器中打开 {productName}，无需 SSH 或远程桌面。主机是运行 {productName} 的那台电脑：Mac、Windows 电脑，或运行 octoboardd 的 Linux 服务器。SSH 登录（macOS 上的“远程登录”）可以保持关闭。

不确定该用哪种方式？请看[选择连接方式](../choose-how-to-connect/)。

<Aside type="caution">
这些步骤尚未完整实测，依据 Tailscale Serve 的文档和 {productName} 自身的检查编写。转发程序已在单台电脑上试过，包括浏览器的实时连接；两台设备之间的 Tailscale Serve 以及 Windows 上的转发尚未实测。
</Aside>

<strong>你电脑上的浏览器</strong> → <strong>你电脑上的转发程序（127.0.0.1）</strong> ⟷ Tailscale ⟷ <strong>主机上的转发程序（127.0.0.1）</strong> → <strong>{productName}</strong>

<details>
<summary>新手须知</summary>

- <strong>Tailscale：</strong>一项把你的设备通过互联网连成私有网络的服务，不管设备在哪里都能用。你用自己的账号登录它。
- <strong>tailnet：</strong>你的 Tailscale 网络，也就是登录了你 Tailscale 账号的那些设备。
- <strong>127.0.0.1（回环地址）：</strong>永远指“本机”的地址。
- <strong>端口：</strong>用来指定电脑上某个程序的编号，就像门牌号。<code dir="ltr">127.0.0.1:{commands.defaultPort}</code> 就是本机的 {commands.defaultPort} 端口。
- <strong>socat：</strong>一个免费的小程序，负责把连接从一处转到另一处。这里用它做转发程序。
- <strong>Tailscale Serve：</strong>Tailscale 的一条命令，只把端口共享给你的 tailnet。与它相近的 Tailscale Funnel 会把端口共享到整个互联网，这里千万不要用。
- <strong>终端：</strong>输入命令的窗口，macOS 上是“终端”，Windows 上是 PowerShell。

</details>

## 为什么要多这几步

出于安全考虑，{productName} 只接受在 <code dir="ltr">{tunnel.loopback}</code>（永远指“本机”的地址，也叫回环地址）上打开的浏览器页面，所以不能直接在浏览器里输入主机的 Tailscale 地址。做法是在两台电脑上各运行一个小的转发程序：你这边的让主机看起来就在本机 <code dir="ltr">{tunnel.loopback}</code> 上，主机那边的把连接交给 {productName}，中间由 Tailscale 传输。

## 连不上时

- <strong>页面打不开：</strong>某个窗口被关掉了，或其中的命令已停止。请确认转发程序和 Tailscale Serve 都还在运行，并且主机上的 <code dir="ltr">{tunnel.serveStatus}</code> 列出了主机端口。
- <strong>socat 提示“Address already in use”：</strong>这台电脑上的该端口已被占用。请换一个端口；如果是你这边的电脑，浏览器地址里也要改成它。
- <strong>页面被拒绝或一片空白：</strong>请确认打开的是 <code dir="ltr">{tunnel.loopback}</code> 开头的地址，而不是主机的 Tailscale 名称或 <code dir="ltr">100.x.y.z</code> 地址。
- <strong>打开页面时，主机上的转发程序提示“Connection refused”或“No such file or directory”：</strong><strong>允许远程访问</strong>没有开启，或主机上的 {productName} 没有运行（Linux 上是 octoboardd 没有运行）。

## 停止使用

- <strong>在用来浏览的电脑上：</strong>按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 停止 socat；在 Windows 上，以管理员身份打开 PowerShell，删除转发：

  <Code code={tunnel.visitorForwardWindowsOff} lang="powershell" />
- <strong>在主机上：</strong>按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 停止 Tailscale Serve 命令和 socat。用 <code dir="ltr">{tunnel.serveStatus}</code> 确认已不再共享任何内容；如果端口仍在列表中，用 <code dir="ltr">{tunnel.serveBridgeOff}</code> 移除它（Windows 上用 <code dir="ltr">{tunnel.serveBrowserPortOff}</code>）。
- <strong>主机是 Mac 或 Windows 时，</strong>不再需要时请关闭<strong>允许远程访问</strong>。这会关闭浏览器入口，并断开所有用该密钥打开的页面。
- <strong>如果地址可能已泄露，</strong>在<strong>浏览器</strong>标签页点击<strong>轮换密钥</strong>给它换一个新密钥，Linux 上运行 <code dir="ltr">{tunnel.rotate}</code>。用旧地址打开的页面会被断开。

## 安全

- <strong>地址就是密码：</strong>地址里的密钥可以完全控制主机上的 {productName}，包括运行任何命令。密钥在你轮换之前一直有效。它会留在浏览器的历史记录和书签里，开启同步后还会同步到你的其他设备。
- <strong>谁能访问：</strong>能访问主机端口并持有密钥的任何人。两台电脑上的转发程序只监听 <code dir="ltr">127.0.0.1</code>，主机所在网络或你本地网络中的其他设备访问不到；Tailscale Serve 只让你的 tailnet 能访问主机端口，并受它的访问规则限制。
- <strong>只在没有其他人登录的电脑上使用：</strong>主机或你电脑上的其他用户账户可以连接这些 <code dir="ltr">127.0.0.1</code> 端口；转发程序没在运行时，他们还可以占用该端口，在你的浏览器重连时拿到密钥。[通过 SSH 连接](../remote-connections/)时，Mac 或 Linux 主机没有这个弱点；用桌面应用时，你自己的电脑也没有。但用浏览器时，你用来浏览的电脑仍有这个弱点，因为那里的 SSH 转发同样监听 <code dir="ltr">127.0.0.1</code> 端口。
- <strong>不要使用 Funnel：</strong>Tailscale Funnel 会把端口公开到整个互联网。
