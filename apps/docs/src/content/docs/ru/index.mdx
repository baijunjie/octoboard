{productName} — это локальное рабочее пространство для разработки с открытым исходным кодом, предназначенное для кодирующих агентов. Оно собирает в одном месте ваших агентов и аккаунты: вы можете запускать сеансы рядом друг с другом, переключать аккаунты без потери беседы, передавать задачи между провайдерами и поручать координирующему агенту распределять работу между несколькими проектами.

Кодирующий агент — это ИИ-помощник, который пишет и запускает код за вас, например Claude Code или Codex. {productName} его не включает: он запускает тех агентов, которые у вас уже есть.

## С чего начать

- **Пользоваться {productName} на этом компьютере:** установите приложение для [macOS](install/macos/) или [Windows](install/windows/). Большинству этого достаточно.
- **Запускать агентов на сервере Linux** (машине, которую вы арендуете или оставляете включённой где-то ещё, обычно без экрана): [установите серверную программу](install/linux/), а затем подключитесь к ней из настольного приложения, как описано в разделе [Подключение по SSH](remote-connections/).
- **Пользоваться {productName} одного компьютера с другого компьютера:** начните с раздела [Выбор способа подключения](choose-how-to-connect/), где способы сравниваются. Коротко:
  - из приложения на другом компьютере или из браузера, при включённом входе по SSH: [Подключение по SSH](remote-connections/);
  - из браузера, без включения входа по SSH: [Браузер через Tailscale](browser-over-tailscale/) или [Браузер через UU Remote](browser-over-uu-remote/).
