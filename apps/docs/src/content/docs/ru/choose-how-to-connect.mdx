{productName} никогда не открывается в сеть сам, поэтому другому компьютеру нужен защищённый путь к нему. SSH — стандартный шифрованный вход, встроенный в macOS, Windows и Linux, и это основной способ: из настольного приложения или из браузера. Если вы не хотите включать вход по SSH на хосте, соединение браузера может передать сторонний ретранслятор: Tailscale или UU Remote.

<strong>Хост</strong> — это машина, на которой работает {productName} и к которой вы хотите подключиться.

<Aside type="tip" title="Самый простой способ">
Если вас устраивают небольшая задержка отклика и размытая картинка, ничего из настроек ниже не нужно: откройте хост в удалённом рабочем столе [UU Remote](https://uuyc.163.com/) и работайте с {productName} прямо на хосте. Это подходит для хоста на Mac или Windows, но не для сервера Linux. Интерфейс UU Remote на китайском. Чтобы получить чёткое и отзывчивое окно на своём компьютере, выберите один из способов ниже.
</Aside>

| | [SSH](../remote-connections/) | [Tailscale](../browser-over-tailscale/) | [UU Remote](../browser-over-uu-remote/) |
| --- | --- | --- | --- |
| Откуда пользоваться | Настольное приложение или браузер | Только браузер | Только браузер |
| Поддерживаемые хосты | Сервер Linux, Mac, компьютер с Windows | Сервер Linux, Mac, компьютер с Windows | Только Mac или компьютер с Windows |
| Что включить или установить на хосте | Вход по SSH (Удалённый вход на Mac, OpenSSH Server в Windows; на сервере Linux он уже есть) | Tailscale | UU Remote |
| Что установить на своём компьютере | Ничего дополнительного | Tailscale; на Mac или Linux также socat | UU Remote (Mac или Windows) |
| Через что идёт трафик | Прямое соединение, без третьих лиц | Сеть Tailscale, с вашим аккаунтом | Сервис NetEase UU Remote, с вашим аккаунтом |
| Работает ли вне одной сети | Только если до хоста можно добраться: из той же сети, по публичному адресу или через VPN | Да | Да |
| Лучше всего подходит для | Серверов; полного настольного приложения; хостов Linux, на которые входят и другие люди, и хостов Mac или Windows, с которыми вы работаете в настольном приложении | Доступа к своим машинам откуда угодно без SSH | Пользователей из материкового Китая, которые уже работают с UU Remote |

## Перед тем как выбрать ретранслятор

Инструкции для ретрансляторов длиннее, чем для SSH: вам нужно выполнять команды на обоих компьютерах и держать их запущенными в открытых окнах, пока вы работаете.

<Aside type="caution">
Инструкции для Tailscale и UU Remote пока не проверены полностью между двумя устройствами. Они основаны на документации этих сервисов и на собственных проверках {productName}.
</Aside>

<Aside type="caution" title="Только на компьютерах, на которые больше никто не входит">
При использовании ретранслятора другая учётная запись на хосте или на вашем компьютере может перехватить ключ браузера. Используйте Tailscale или UU Remote только на компьютерах, на которые входите только вы. [Подключение по SSH](../remote-connections/) не имеет этой слабости на хосте Linux с выключенным доступом из браузера и на хосте Mac или Windows при работе в настольном приложении, а ваш собственный компьютер её не имеет при работе в настольном приложении. В браузере у вашего компьютера она остаётся, потому что перенаправление SSH там тоже слушает порт <code dir="ltr">127.0.0.1</code>.
</Aside>
