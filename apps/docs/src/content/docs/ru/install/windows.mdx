Для компьютеров с процессором Intel или AMD (x64; почти все компьютеры с Windows), Windows 10 версии 21H2 или новее. В Windows 11 на Arm используйте нативный установщик arm64, если он есть в выпуске; иначе это приложение x64 работает там через эмуляцию.

## Установка

<Steps>

1. Скачайте установщик кнопкой выше. Это файл, имя которого заканчивается на <code dir="ltr">x64-setup.exe</code>. В Windows на Arm попробуйте вторую кнопку: если в выпуске есть установщик arm64, она скачивает этот файл, имя которого заканчивается на <code dir="ltr">arm64-setup.exe</code>; иначе она открывает список выпусков, и установщик x64 работает через эмуляцию.
2. Откройте скачанный файл, чтобы запустить установщик. Он устанавливает {productName} только для вашей учётной записи, поэтому права администратора не запрашиваются.

   Приложение пока не имеет цифровой подписи, поэтому Microsoft Defender SmartScreen может показать сообщение «Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

   Если на компьютере нет Microsoft Edge WebView2, который отрисовывает окно приложения, установщик скачает его, поэтому не отключайтесь от интернета.
3. Откройте {productName} из меню «Пуск».
4. Установите хотя бы одного кодирующего агента (см. ниже), затем нажмите <strong>Добавить проект</strong> в {productName}, чтобы открыть папку проекта.

</Steps>

Когда откроется главное окно, всё готово.

## Установка кодирующего агента

{productName} не включает ИИ-агента. Установите тех, которыми хотите пользоваться, по их собственным инструкциям и войдите в них. {productName} найдёт их автоматически. Он работает с:

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)
- [Antigravity CLI](https://antigravity.google/product/antigravity-cli)
- [GitHub Copilot CLI](https://github.com/github/copilot-cli)
- [OpenCode](https://opencode.ai)
- [Qwen Code](https://github.com/QwenLM/qwen-code)
- [Pi](https://github.com/earendil-works/pi)

Если вы пользуетесь Claude Code или Codex, сначала установите [Git for Windows](https://git-scm.com/download/win): без него они не работают.

## Удаление

Удалите {productName} его программой удаления — из «Параметров» Windows (раздел «Приложения») или из панели управления.

<WindowsUninstaller />

Чтобы перед удалением увидеть, что сейчас действует, откройте <strong>Настройки › Очистка › Очистка перед удалением приложения</strong>: <strong>Убрать всё</strong> там убирает то же самое и показывает результат по каждому элементу.

На странице [Ваша система остаётся прежней](../../your-system/) сказано, что остаётся после этого и как это убрать.
