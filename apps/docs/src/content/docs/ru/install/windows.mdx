Для компьютеров с процессором Intel или AMD (x64; почти все компьютеры с Windows), Windows 10 версии 21H2 или новее. В Windows 11 на Arm это приложение x64 работает через эмуляцию.

<Aside>Приложение для Windows находится на стадии беты.</Aside>

## Установка

<Steps>

1. Скачайте установщик кнопкой выше. Это файл, имя которого заканчивается на <code dir="ltr">x64-setup.exe</code>.
2. Откройте скачанный файл, чтобы запустить установщик. Он устанавливает {productName} только для вашей учётной записи, поэтому права администратора не запрашиваются.

   Приложение пока не имеет цифровой подписи, поэтому Microsoft Defender SmartScreen может показать сообщение «Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

   Если на компьютере нет Microsoft Edge WebView2, который отрисовывает окно приложения, установщик скачает его, поэтому не отключайтесь от интернета.
3. Откройте {productName} из меню «Пуск».
4. Установите хотя бы одного кодирующего агента (см. ниже), затем нажмите <strong>Добавить проект</strong> в {productName}, чтобы открыть папку проекта.

</Steps>

Когда откроется главное окно, всё готово.

## Установка кодирующего агента

{productName} не включает ИИ-агента. Установите тех, которыми хотите пользоваться, по их собственным инструкциям и войдите в них. {productName} найдёт их автоматически. Он работает с:

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)

Если вы пользуетесь Claude Code или Codex, сначала установите [Git for Windows](https://git-scm.com/download/win): без него они не работают.

## Обновления

Когда выходит новая версия, {productName} сообщает об этом, и вы можете установить её прямо в приложении. Возвращаться на эту страницу не нужно.

## Командная строка

Из PowerShell можно проверить, запущен ли {productName}, включить или выключить доступ из браузера и вывести его адрес для браузера. Как это сделать, описано на странице [Командная строка](../../command-line/).
