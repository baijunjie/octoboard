Open {productName} in a browser on another computer through your own Tailscale network, without SSH or a remote desktop. The host is the computer that runs {productName}: a Mac, a Windows PC or a Linux server running octoboardd. SSH sign-in (Remote Login on macOS) can stay off.

Not sure this is the way for you? See [Choose how to connect](../choose-how-to-connect/).

<Aside type="caution">
These steps haven't been fully tested yet. They follow the Tailscale Serve documentation and {productName}'s own checks. The relay programs were tried on a single computer, including the browser's live connection; Tailscale Serve between two devices and the Windows forward have not been tried yet.
</Aside>

<strong>Browser on your computer</strong> → <strong>relay on your computer (127.0.0.1)</strong> ⟷ Tailscale ⟷ <strong>browser port on the host (127.0.0.1)</strong> → <strong>{productName}</strong>

<details>
<summary>New to this?</summary>

- <strong>Tailscale:</strong> a service that links your devices into a private network over the internet, wherever they are. You sign in to it with your own account.
- <strong>Tailnet:</strong> your Tailscale network: the devices signed in to your Tailscale account.
- <strong>127.0.0.1 (loopback):</strong> an address that always means “this same computer”.
- <strong>Port:</strong> a number that picks one program on a computer, like a door number. <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> is port {commands.defaultPort} on this computer.
- <strong>socat:</strong> a small, free program that passes a connection from one place to another. Here it's the relay.
- <strong>Tailscale Serve:</strong> a Tailscale command that shares a port with your tailnet only. Its cousin, Tailscale Funnel, would share it with the whole internet; never use it here.
- <strong>Terminal:</strong> the window you type commands into: Terminal on macOS, PowerShell on Windows.

</details>

## Why the extra steps

For safety, {productName} only accepts a browser that opens it at <code dir="ltr">{tunnel.loopback}</code>, an address that always means “this same computer” (also called loopback). So you can't just type the host's Tailscale address into the browser. Instead, a relay or forward on your computer makes the host look local at <code dir="ltr">{tunnel.loopback}</code>, and Tailscale carries the traffic between the two. On the host, {productName} itself listens on a loopback port, so there is nothing to run there.

## Before you start

- <strong>Tailscale on both computers,</strong> signed in to the same tailnet. Use a tailnet that holds only your own devices: every device it lets reach the host can reach the port you share.
- <strong>socat on each Mac or Linux computer you browse from.</strong> A host never needs it, and neither does a Windows computer you browse from.

## If it doesn't work

- <strong>The page doesn't load:</strong> a window was closed, or its command stopped. Check that the relay on your computer and Tailscale Serve are still running, and that <code dir="ltr">{tunnel.serveStatus}</code> on the host lists the host port.
- <strong>socat says “Address already in use”:</strong> that port is taken on that computer. Pick another port; on your computer, change it in the browser address too.
- <strong>The page is refused or blank:</strong> check that you opened the address at <code dir="ltr">{tunnel.loopback}</code>, not the host's Tailscale name or <code dir="ltr">100.x.y.z</code> address.
- <strong>The relay on your computer prints “Connection refused”, or the page is refused, when you open it:</strong> <strong>Allow browser access</strong> is off, another program holds the browser port (Settings says so), or {productName} isn't running on the host (on Linux, octoboardd isn't running, or <code dir="ltr">{commands.browserOn}</code> hasn't been run).

## Turn it off

- <strong>On the computer you browsed from:</strong> stop socat with <kbd>Ctrl</kbd>+<kbd>C</kbd>, or on Windows delete the forward in PowerShell run as administrator:

  <Code code={tunnel.visitorForwardWindowsOff} lang="powershell" />
- <strong>On the host:</strong> stop the Tailscale Serve command with <kbd>Ctrl</kbd>+<kbd>C</kbd>. Check with <code dir="ltr">{tunnel.serveStatus}</code> that nothing is shared any more; if the port is still listed, remove it with <code dir="ltr">{tunnel.serveBrowserPortOff}</code>.
- <strong>On a Mac or Windows host,</strong> turn off <strong>Allow browser access</strong> when you no longer need it. This closes the browser port and disconnects every page opened with the key.
- <strong>On a Linux host,</strong> run <code dir="ltr">{commands.browserOff}</code> when you no longer need it. This closes the browser port and disconnects every page opened with the key.
- <strong>If the address may have leaked,</strong> give it a new key with <strong>Rotate key</strong> in <strong>Settings › Access</strong>, or on Linux with <code dir="ltr">{tunnel.rotate}</code>. Pages open with the old address are disconnected.

## Security

- <strong>The address is the password:</strong> its key gives full control of {productName} on the host, running any command included. It lasts until you rotate it. It stays in the browser's history and bookmarks, and syncs to your other devices if browser sync is on.
- <strong>Who can reach it:</strong> anyone who reaches the host port and has the key. The browser port and the relay listen on <code dir="ltr">127.0.0.1</code> only, so other devices on the host's or your local network can't reach them; Tailscale Serve makes the host port reachable from your tailnet only, as far as its access rules allow.
- <strong>Only on computers nobody else signs in to:</strong> another user account on the host or on your computer can connect to these <code dir="ltr">127.0.0.1</code> ports, and can take the host's browser port while {productName} isn't running or is restarting, or your computer's relay port while the relay isn't running, and receive the key when your browser reconnects. With [Connect over SSH](../remote-connections/), a Linux host with browser access off doesn't have this weakness, nor does a Mac or Windows host you use from the desktop app, and neither does your own computer when you use the desktop app. In a browser your computer still has it, because the SSH forward listens on a <code dir="ltr">127.0.0.1</code> port there too.
- <strong>Never Funnel:</strong> Tailscale Funnel would publish the port to the whole internet.
