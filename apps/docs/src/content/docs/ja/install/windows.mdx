Intel または AMD プロセッサ搭載の PC（x64。ほとんどの Windows PC）に対応。Windows 10 バージョン 21H2 以降で使えます。Arm 版 Windows 11 では、リリースにネイティブの arm64 版インストーラーがあればそれを使います。ない場合は、この x64 版アプリがエミュレーションで動きます。

<LinkButton href={downloads["windows-arm64"]} variant="secondary">Windows Arm64 版をダウンロード</LinkButton>

<Aside>Windows 版アプリはベータ版です。</Aside>

## インストール

<Steps>

1. 上のボタンからインストーラーをダウンロードします。名前が <code dir="ltr">x64-setup.exe</code> で終わるファイルです。Arm 版 Windows では 2 つ目のボタンを試します。リリースに arm64 版インストーラーがあれば、名前が <code dir="ltr">arm64-setup.exe</code> で終わるそのファイルをダウンロードします。ない場合はリリース一覧が開くので、エミュレーションで動く x64 版インストーラーを使います。
2. ダウンロードしたファイルを開いて、インストーラーを実行します。{productName} は自分のユーザーアカウントだけにインストールされるので、管理者の許可は求められません。

   アプリにはまだコード署名がないため、Microsoft Defender SmartScreen が「Windows によって PC が保護されました」と表示することがあります。その場合は「詳細情報」を選び、続けて「実行」を選びます。

   アプリのウィンドウを描画する Microsoft Edge WebView2 が PC に入っていない場合は、インストーラーがダウンロードします。インターネットにつないだままにしてください。
3. スタートメニューから {productName} を開きます。
4. コーディングエージェントを 1 つ以上インストールし（下記参照）、{productName} で<strong>プロジェクトを追加</strong>を選んで、プロジェクトのフォルダを開きます。

</Steps>

メインウィンドウが開いたら完了です。

## コーディングエージェントをインストールする

{productName} には AI エージェントは含まれていません。使いたいエージェントを、それぞれの案内に従ってインストールし、サインインしてください。{productName} が自動で見つけます。対応しているのは次のエージェントです。

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)
- [Antigravity CLI](https://antigravity.google/product/antigravity-cli)
- [GitHub Copilot CLI](https://github.com/github/copilot-cli)
- [OpenCode](https://opencode.ai)
- [Qwen Code](https://github.com/QwenLM/qwen-code)
- [Pi](https://github.com/earendil-works/pi)

Claude Code または Codex を使う場合は、先に [Git for Windows](https://git-scm.com/download/win) をインストールしてください。動作に必要です。

## アンインストール

Windows の設定（アプリ）またはコントロールパネルから、{productName} のアンインストーラーでアンインストールします。

<WindowsUninstaller />

アンインストールの前に何が有効になっているかを確かめるには、<strong>設定 › クリーンアップ › アンインストール前のクリーンアップ</strong>を開きます。そこにある<strong>すべて削除</strong>も同じものを削除し、項目ごとの結果を表示します。

あとに何が残るか、それをどう削除するかは、[システムは元のまま](../../your-system/)で説明しています。
