このコンピューターから、Linux サーバーや別のコンピューターの {productName} を、デスクトップアプリまたはブラウザで SSH 経由で使います。相手のマシンへの暗号化された直接接続で、中継サービスやクラウドサービスは使いません。

この方法が自分に合っているかわからない場合は、[接続方法を選ぶ](../choose-how-to-connect/)で、SSH が不要なブラウザ専用の方法と比べてみてください。

<strong>このコンピューターのデスクトップアプリ</strong> · <strong>SSH フォワード経由のブラウザ</strong> ⟷ SSH ⟷ <strong>Linux サーバーまたは別のコンピューター</strong>

<details>
<summary>はじめての方へ</summary>

- <strong>ホスト:</strong> {productName} が動いていて、つなぎたい相手のマシンのことです。Linux サーバー、または別の Mac や Windows PC です。
- <strong>サーバー:</strong> ここでは、ネットワーク越しにサインインする Linux マシンのことです。たいていは借りているもので、画面はありません。
- <strong>SSH:</strong> 別のマシンに安全にサインインして、コマンドを入力するための、標準的で暗号化された方法です。macOS、Windows、Linux に標準で入っています。
- <strong>ターミナル:</strong> コマンドを入力するウィンドウです。macOS ではターミナル、Windows では PowerShell を使います。
- <strong>SSH フォワード:</strong> ホスト上にあるものを自分のコンピューター上に見せるための SSH コマンドです。これで、自分のブラウザからそれを開けるようになります。
- <strong>フィンガープリント（ホスト鍵）:</strong> マシンの SSH を見分けるための短いコードです。一度確認しておけば、正しいマシンにつながったとわかります。
- <strong>鍵ファイル:</strong> パスワードの代わりにサインインに使うファイルです。サーバーの提供元から渡されることがあります。

</details>

  <Code code={commands.signIn} lang="sh" />

  ホストが Mac や Windows PC の場合は、そのシステム設定で SSH ログインをオンにします。やり方は[別のコンピューターをホストにする](#別のコンピューターをホストにする)で説明します。
- <strong>Linux サーバーの場合は、そこにインストールして起動した {productName}。</strong>やり方は[インストール › Linux サーバー](../install/linux/)にあります。{productName} のサーバー用プログラム octoboardd を、アプリでは「デーモン」と呼びます。
- <strong>このコンピューターに入れた {productName} アプリ。</strong>macOS 用または Windows 用です。ブラウザだけで使う場合は不要です。

## 別のコンピューターをホストにする

{productName} アプリが動いている Mac や Windows PC につなぐこともできます。

<Steps>

1. つなぎたいコンピューターで、{productName} の<strong>設定 › アクセス</strong>を開きます。
2. そこで<strong>システム設定を開く</strong>（macOS）または <strong>設定を開く</strong>（Windows）を選び、その行が示す手順に従って<strong>リモートログイン</strong>（macOS）または <strong>OpenSSH Server</strong>（Windows）をオンにします。これで、このコンピューターが SSH でのサインインを受け付けるようになります。管理者の権限が必要です。{productName} に戻ると、その行に<strong>オン</strong>と表示されます。
3. <strong>リモートアクセスを許可</strong>をオンにし、<strong>許可</strong>を選んで確定します。{productName} は起動したままにしてください。終了すると、リモートアクセスも止まります。
4. <strong>接続情報をコピー</strong>を選び、もう一方のコンピューターに、たとえばメールやチャットで送ります。
5. 作業に使うコンピューターで、[Linux サーバーに接続する](#linux-サーバーに接続する)の手順 2 から 5 と同じようにホストを追加し、送られてきた情報を貼り付けます。ホストのユーザー名とパスワードでサインインします。

</Steps>

別のウィンドウが開いて、ホストのプロジェクトとセッションが表示されれば成功です。

## ブラウザから接続する

<Steps>

1. SSH フォワードのコマンドを手に入れます。

   - <strong>ホストが Linux サーバーの場合は、</strong>サーバーで次のコマンドを実行します。ブラウザのアドレスに続けて、実行する SSH コマンドが表示されます。

     <Code code={commands.address} lang="sh" />

     コマンド中の <code dir="ltr">{commands.server}</code> を、サーバーのアドレスに置き換えます。
2. ブラウザを使うコンピューターで、ターミナル（macOS）または PowerShell（Windows）から SSH コマンドを実行します。パスワードを聞かれることがあり、その後は何も表示されませんが、正常です。作業している間はウィンドウを開いたままにしてください。閉じると、ブラウザの接続が切れます。

このアドレスを使えるのは、SSH フォワード経由で {productName} に届く人だけです。ほかの人に知られないようにしてください。アドレスに含まれるキーでフルコントロールができ、ブラウザの履歴やブックマークに残ります。ブラウザの同期がオンなら、ほかのデバイスにも同期されます。

## うまくいかないとき

- <strong>「サーバーに接続できませんでした」と表示される、または SSH コマンドが「Connection refused」と表示されたりタイムアウトしたりする:</strong> ホストで SSH ログインがオフになっているか、アドレスまたは SSH ポートが違っています。<strong>リモートログイン</strong>または <strong>OpenSSH Server</strong> がオンになっているか、上の <code dir="ltr">ssh</code> コマンドでサインインできるかを確認してください。
- <strong>「サインインできませんでした」と表示される、または「Permission denied」と表示される:</strong> ユーザー名、パスワード、鍵ファイルのどれかが違っています。
- <strong>「ホスト鍵が一致しません」と表示される:</strong> 応答しているマシンが、以前に接続したものと別のマシンです。サーバーを入れ直したあとに起きることがありますが、何か問題が起きている可能性もあります。理由がわかるまで、先へ進まないでください。
- <strong>ブラウザのページが開かない:</strong> SSH のウィンドウが閉じられたか、コマンドが止まっています。もう一度実行して、ページを再読み込みしてください。

## セキュリティ

- <strong>公開ポートを増やさない:</strong> {productName} はホスト自身からの接続しか受け付けません。そのため、別のコンピューターからつなぐには、まず SSH でホストにサインインする必要があります。SSH が必要なのも、[中継サービス](../choose-how-to-connect/)のどれかが必要なのも、このためです。
- <strong>どのマシンにつながるかを確認する:</strong> アプリは初めて接続できたときに、ホスト鍵（マシンの SSH の身元）を記憶し、あとでその身元が変わると、警告を出して接続を止めます。
- <strong>パスワードは保存しない:</strong> パスワードまたは自分の鍵ファイルで最初にサインインしたあと、アプリはこのコンピューター専用の別の SSH 鍵を作り、以降のサインインにはそれを使います。
- <strong>コンピューターのアクセスを取り消す:</strong> ホストの、許可する SSH 鍵の一覧（Linux と macOS では <code dir="ltr">{commands.authorizedKeys}</code>）から、そのコンピューターのエントリを削除します。その鍵では二度とサインインできなくなります。すでに開いている接続は、終了するまで残ります。

## リモートウィンドウでの操作

- <strong>SSH の接続先ごとに 1 つのウィンドウ:</strong> ユーザー名、ホスト、SSH ポートのどれかが違う接続は、それぞれ別のウィンドウで開きます。プロジェクト、セッション、通知が混ざることはありません。
- <strong>接続ごとの状態を見る:</strong> macOS ではアプリのメニューバーのアイコン、Windows では通知領域のアイコンを開くと、接続ごとのタブが表示されます。
- <strong>リモートのウェブサイトをここで開く:</strong> エージェントがホスト上でウェブサイトを起動したときは、表示される <code dir="ltr">{commands.localhost}</code> のリンクをクリックします。アプリが SSH 経由で、そのウェブサイトをこのコンピューターで開きます。
- <strong>リモートのファイルをここで開く:</strong> リモートウィンドウでファイルを表示したり、コピーをダウンロードして、このコンピューターでそのファイルの既定のアプリで開いたりできます。
- <strong>自動で再接続する:</strong> ネットワークが切れても、つながるか、ウィンドウを閉じるまで、ウィンドウが再接続を試み続けます。
