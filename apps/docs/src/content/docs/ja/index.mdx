{productName} は、コーディングエージェント向けの、ローカルで動くオープンソースの開発ワークスペースです。すでに使っているエージェントやアカウントを 1 か所にまとめます。セッションを並べて実行したり、会話を保ったままアカウントを切り替えたり、プロバイダー間でタスクを引き継いだり、調整役のエージェントに複数のプロジェクトへ仕事を振り分けさせたりできます。

コーディングエージェントとは、コードを書いて実行してくれる AI アシスタントのことで、Claude Code や Codex などがあります。{productName} 自体には含まれていません。すでにお持ちのエージェントを動かすためのものです。

## どこから始めるか

- **このコンピューターで {productName} を使う:** [macOS](install/macos/) または [Windows](install/windows/) 用のアプリをインストールします。ほとんどの方はこれだけで十分です。
- **Linux サーバーでエージェントを動かす**（借りているマシンなど、どこかで動かし続けている、たいていは画面のないマシン）: [サーバー用プログラムをインストール](install/linux/)し、[SSH で接続](remote-connections/)で説明している手順でデスクトップアプリからつなぎます。
- **別のコンピューターの {productName} を、今のコンピューターから使う:** まず[接続方法を選ぶ](choose-how-to-connect/)で、つなぎ方を比べてください。ざっくり言うと次のとおりです。
  - もう一方のコンピューターのアプリから、または SSH ログインをオンにしたうえでブラウザから使う: [SSH で接続](remote-connections/)
  - SSH ログインをオンにせず、ブラウザから使う: [Tailscale 経由のブラウザ](browser-over-tailscale/)または [UU Remote 経由のブラウザ](browser-over-uu-remote/)
