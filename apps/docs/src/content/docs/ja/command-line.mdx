octoboardd は {productName} を動かすプログラムです（アプリでは「デーモン」と呼びます）。Linux サーバーでは、自分でインストールして起動します。Mac や Windows PC ではアプリに含まれていて、アプリが開くと起動し、終了すると停止します。コマンドは 3 つの環境で共通で、違いは以下のとおりです。

## octoboardd を実行する

- <strong>Linux サーバー:</strong> インストールすると、<code dir="ltr">octoboardd</code> が PATH に追加されます。シェルが見つけられない場合は、[octoboardd が見つからないとき](../install/linux/#octoboardd-が見つからないとき)を参照してください。
- <strong>macOS:</strong> アプリで<strong>設定 › 一般</strong>を開き、<strong>コマンドラインツール</strong>の横の<strong>インストール</strong>を選びます。続けて PATH にディレクトリを追加するよう求められたら、それも行ってください。以降は、ターミナルが名前だけで <code dir="ltr">octoboardd</code> を見つけます。
- <strong>Windows:</strong> インストールするものはありません。PowerShell では、次のようにフルパスで実行します。

  <Code code={commands.windowsStatus} lang="powershell" />

コマンドは、{productName} を動かしているユーザーとして実行します。どれも、そのユーザーの octoboardd に作用します。

## コマンド

| コマンド | 動作 |
| --- | --- |
| <code dir="ltr">{commands.start}</code> | octoboardd をバックグラウンドで起動します。コマンドが終わっても動き続けます。 |
| <code dir="ltr">{commands.status}</code> | octoboardd が動いているかどうかを表示します。 |
| <code dir="ltr">{commands.stop}</code> | octoboardd を停止し、すべてのセッションを中断します。各セッションは、octoboardd が再び動いてから再開できます。作業が進行中の場合は、その作業を一覧で示して何も停止しません。<code dir="ltr">{commands.stopForce}</code> を使うと、それでも停止します。 |
| <code dir="ltr">{commands.restart}</code> | Linux サーバーのみ。octoboardd を再起動し、すべてのセッションを動かしたままにします。中断されるセッションがある場合は、それを一覧で示して先に確認します。ブラウザのアドレスは変わりません。 |
| <code dir="ltr">{commands.address}</code> | ブラウザのアドレスと、そこにつながる <code dir="ltr">ssh</code> コマンドを表示します。 |
| <code dir="ltr">{tunnel.rotate}</code> | ブラウザのアドレスのキーを新しいキーに替え、新しいアドレスを表示します。以前のアドレスはすべて使えなくなり、古いキーで接続していたものは切断されます。 |
| <code dir="ltr">{commands.connection}</code> | 別のコンピューターのデスクトップアプリが設定に使う接続情報を、QR コードと 1 行のテキストで表示します。 |
| <code dir="ltr">{commands.browserOn}</code> | このコンピューター自体でブラウザ用ポートを開きます。ポート番号は、別に設定しない限り <code dir="ltr">{commands.defaultPort}</code> です。このコンピューター上のブラウザや Tailscale などのツール向けです。Linux サーバーへの SSH 接続には必要ありません。ほかの人がサインインしないコンピューターでのみオンにしてください。 |
| <code dir="ltr">{commands.browserOff}</code> | ブラウザ用ポートと、それを通した接続をすべて閉じます。 |
| <code dir="ltr">{commands.browserStatus}</code> | ブラウザ用ポートが開いているかどうかと、そのポート番号を表示します。 |
| <code dir="ltr">{commands.update}</code> | Linux サーバーのみ。最新のバージョンをインストールします。[アップグレード](../install/linux/#アップグレード)と同じです。 |
| <code dir="ltr">{commands.updateCheck}</code> | Linux サーバーのみ。新しいバージョンが出ているかどうかを確認します。インストールはしません。 |
| <code dir="ltr">{commands.updateRollback}</code> | Linux サーバーのみ。直前のアップグレードより前にインストールされていたバージョンに戻し、アップグレードのときと同じようにそのバージョンで再起動します。 |
| <code dir="ltr">{system.uninstall}</code> | Linux サーバーのみ。サーバーから octoboardd を削除します。[アンインストール](../install/linux/#アンインストール)と同じです。 |
| <code dir="ltr">{commands.version}</code> | インストールされているバージョンを表示します。 |

コマンドの一覧は <code dir="ltr">{commands.help}</code> で、1 つのコマンドのオプションは <code dir="ltr">{commands.commandHelp}</code> で確認できます。一覧には {productName} が内部で実行するコマンドも含まれますが、これらを手動で実行することはありません。

## Mac または Windows PC では

アプリが octoboardd を動かすため、いくつかのコマンドは動作が異なります。

- <strong>Mac での <code dir="ltr">{commands.start}</code> と <code dir="ltr">{commands.stop}</code></strong> は、アプリに作用します。<code dir="ltr">{commands.start}</code> はウィンドウなしでアプリをバックグラウンドで開き、<code dir="ltr">{commands.stop}</code> はアプリを終了します。
- <strong><code dir="ltr">{commands.restart}</code> と <code dir="ltr">{commands.update}</code></strong> は拒否されます。octoboardd の再起動も新しいバージョンのインストールも、アプリが自分で行います。
- <strong><code dir="ltr">{system.uninstall}</code></strong> も拒否されます。octoboardd はアプリと一緒に削除されます。アプリのアンインストール方法は [macOS](../install/macos/#アンインストール) と [Windows](../install/windows/#アンインストール) で説明しています。
- <strong><code dir="ltr">{commands.browserOn}</code> と <code dir="ltr">{commands.browserOff}</code></strong> は、<strong>設定 › アクセス</strong>の<strong>ブラウザアクセスを許可</strong>と同じ設定を変更します。
- <strong><code dir="ltr">{commands.address}</code></strong> は、<strong>ブラウザアクセスを許可</strong>（Mac では<strong>リモートアクセスを許可</strong>）がオンのときだけアドレスを表示します。この 2 つの設定は初期状態でオフなので、どちらかをオンにするまでは、その旨を表示し、アドレスは表示しません。
