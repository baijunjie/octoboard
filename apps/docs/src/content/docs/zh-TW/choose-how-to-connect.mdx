{productName} 從不直接對網路開放，另一台電腦需要一條安全通道才能連到它。SSH 是 macOS、Windows 和 Linux 都內建的通用加密登入方式，也是主要的連線方式：桌面應用程式和瀏覽器都能用。如果你不想在主機上開啟 SSH 登入，也可以借助第三方中繼服務（Tailscale 或 UU 遠程），讓瀏覽器連過去。

<strong>主機</strong>指執行 {productName}、你要連過去的那台機器。

<Aside type="tip" title="最簡單的方式">
如果可以接受一些操作延遲和畫面模糊，就不必做下面這些設定：用 [UU 遠程](https://uuyc.163.com/)的遠端桌面開啟主機，直接在主機上使用 {productName}。適用於 Mac 或 Windows 主機，不適用於 Linux 伺服器。如果想在自己的電腦上獲得清晰流暢的操作，就從下面選一種方式。
</Aside>

## 選擇中繼服務之前

中繼方式的步驟比 SSH 多：要在兩台電腦上執行指令，並在使用期間讓它們在開著的視窗裡持續執行。

<Aside type="caution">
Tailscale 和 UU 遠程的指南尚未在兩台裝置之間完整實測，它們是依據這兩項服務自己的文件和 {productName} 本身的檢查撰寫的。
</Aside>

<Aside type="caution" title="只在沒有其他人登入的電腦上使用">
使用中繼服務時，主機或你電腦上的其他使用者帳戶有可能攔截瀏覽器的金鑰。請只在只有你自己登入的電腦上使用 Tailscale 或 UU 遠程。透過 SSH 連線時，Mac 或 Linux 主機沒有這個弱點；用桌面應用程式時，你自己的電腦也沒有。但用瀏覽器時，你用來瀏覽的電腦仍有這個弱點，因為那裡的 SSH 轉送同樣監聽 <code dir="ltr">127.0.0.1</code> 連接埠。
</Aside>
