透過網易遠端控制軟體 [UU 遠程](https://uuyc.163.com/)的連接埠對應，在另一台電腦的瀏覽器中開啟 {productName}，不需要 SSH 或遠端桌面。主機是執行 {productName} 的那台電腦；SSH 登入（macOS 上的「遠端登入」）可以保持關閉，也不需要遠端桌面工作階段。UU 遠程的介面只有簡體中文，本指南會照它介面上的文字標示。

本頁介紹的是在自己電腦的瀏覽器中開啟 {productName}，這種方式比遠端桌面清晰流暢，但步驟較多。如果不介意延遲和模糊，直接用 UU 遠程的遠端桌面在主機上操作即可。

不確定該用哪種方式？請看[選擇連線方式](../choose-how-to-connect/)。

<Aside type="caution">
這些步驟尚未在兩台裝置之間實測，是依據 UU 遠程本身的說明撰寫的。Mac 主機上的轉送程式已在單台電腦上試過，包括瀏覽器的即時連線。
</Aside>

<strong>你電腦上的瀏覽器</strong> → <strong>你電腦上的 127.0.0.1</strong> ⟷ UU 遠程 ⟷ <strong>主機上的 127.0.0.1</strong> → <strong>{productName}</strong>

<details>
<summary>新手須知</summary>

- <strong>127.0.0.1（回送位址）：</strong>永遠代表「本機」的位址。
- <strong>連接埠：</strong>用來指定電腦上某個程式的編號，就像門牌號碼。<code dir="ltr">127.0.0.1:{commands.defaultPort}</code> 就是本機的 {commands.defaultPort} 連接埠。
- <strong>連接埠對應（介面上為「端口映射」）：</strong>UU 遠程的一項功能，讓主機上的某個連接埠出現在你自己的電腦上。
- <strong>socat：</strong>一個免費的小程式，負責把連線從一處轉到另一處。Mac 主機需要用它當作轉送程式。
- <strong>終端機：</strong>輸入指令的視窗，macOS 上是「終端機」，Windows 上是 PowerShell。

</details>

UU 遠程的連接埠對應會讓主機上的 {productName} 出現在你自己電腦的 <code dir="ltr">{tunnel.loopback}</code> 上，而 {productName} 只接受這個位址上的瀏覽器存取。

## 準備工作

- <strong>兩台電腦都是 Mac 或 Windows 電腦。</strong>UU 遠程沒有 Linux 版的連接埠對應；請改用 [Tailscale](../browser-over-tailscale/) 或 [SSH](../remote-connections/) 存取 Linux 伺服器。
- <strong>兩台電腦都安裝好 UU 遠程，並登入同一個帳號，</strong>Windows 上需要 4.21.0 以上版本，macOS 上需要 4.32.0 以上版本。連接埠對應只支援 TCP，{productName} 也只需要 TCP。撰寫本文時，UU 遠程把連接埠對應列為免費功能；如有疑問，請查看它目前的方案說明。
- <strong>在用來瀏覽的電腦上，UU 遠程的「我的设备」中看得到這台主機。</strong>
- <strong>主機是 Mac 時，還需要 [Homebrew](https://brew.sh/)</strong>，用來安裝下文的 socat。

## 在用來瀏覽的電腦上

<Steps>

1. 在 UU 遠程中，從<strong>我的设备</strong>開啟主機，點選裝置卡片上的<strong>更多</strong>，選擇<strong>端口映射</strong>，然後新增一條對應：

   | 欄位 | 值 |
   | --- | --- |
   | 名称 | {productName} |
   | 本地端口 | <code dir="ltr">{commands.defaultPort}</code> |
   | 目标地址 | <code dir="ltr">127.0.0.1</code> |
   | 目标端口 | 主機連接埠 |

   儲存並啟用，等它顯示已連線。如果這台電腦上的 {commands.defaultPort} 連接埠已被占用，請換一個本地連接埠，並在瀏覽器位址中也改成它。
2. 確認只有這台電腦能使用這條對應。在這台電腦上開啟「終端機」（macOS）或 PowerShell（Windows），執行：

   <Tabs syncKey="visitor">
   <TabItem label="macOS">
   <Code code={tunnel.checkListener} lang="sh" />

   輸出中應該有一行同時包含 <code dir="ltr">127.0.0.1:{commands.defaultPort}</code> 和 <code dir="ltr">LISTEN</code>。
   </TabItem>
   <TabItem label="Windows">
   <Code code={tunnel.checkListenerWindows} lang="powershell" />

   輸出中應該有一行以 <code dir="ltr">TCP</code> 開頭、接著是 <code dir="ltr">127.0.0.1:{commands.defaultPort}</code>，並以 <code dir="ltr">LISTENING</code> 和一個數字結尾。
   </TabItem>
   </Tabs>

   如果那個位置顯示的是 <code dir="ltr">*:{commands.defaultPort}</code> 或 <code dir="ltr">0.0.0.0:{commands.defaultPort}</code>，請刪除這條對應：你網路中的其他裝置也能存取 {productName}。
3. 開啟在主機上複製的瀏覽器位址。它以 <code dir="ltr">{tunnel.addressStart}</code> 開頭。

</Steps>

看到 {productName} 在瀏覽器分頁中開啟，而且沒有要求你登入，就表示成功了。

## 連不上時

- <strong>對應顯示已連線，但頁面打不開：</strong>主機是 Mac 時，socat 的視窗被關掉了或指令已停止；或者<strong>允許遠端存取</strong>沒有開啟，或主機上的 {productName} 沒有在執行。
- <strong>對應無法儲存或連不上：</strong>這台電腦上的本地連接埠可能已被占用。請換一個，並在瀏覽器位址中也改成它。
- <strong>頁面被拒絕或一片空白：</strong>請確認開啟的是 <code dir="ltr">{tunnel.loopback}</code> 開頭的位址。

## 停止使用

- <strong>在用來瀏覽的電腦上：</strong>在 UU 遠程的端口映射面板中停用或刪除這條對應。關閉面板或中斷連線也會讓對應停止。
- <strong>主機是 Mac 時：</strong>按 <kbd>Ctrl</kbd>+<kbd>C</kbd> 停止 socat。
- <strong>在主機上，</strong>不再需要時請關閉<strong>允許遠端存取</strong>。這會關閉瀏覽器入口，並中斷所有用該金鑰開啟的頁面。
- <strong>如果位址可能已外洩，</strong>在<strong>瀏覽器</strong>分頁點選<strong>輪替金鑰</strong>為它換一把新金鑰。用舊位址開啟的頁面會被中斷。

## 安全性

- <strong>位址就是密碼：</strong>位址裡的金鑰可以完全控制主機上的 {productName}，包括執行任何指令。金鑰在你輪替之前一直有效。它會留在瀏覽器的瀏覽紀錄和書籤裡，開啟同步後還會同步到你的其他裝置。
- <strong>誰能存取：</strong>能連到主機連接埠並持有金鑰的任何人。主機上的連接埠只監聽 <code dir="ltr">127.0.0.1</code>；能用你的 UU 遠程帳號對這台主機進行連接埠對應的人也能存取它，請妥善保管這個帳號。
- <strong>只在沒有其他人登入的電腦上使用：</strong>主機或你電腦上的其他使用者帳戶可以連到這些 <code dir="ltr">127.0.0.1</code> 連接埠；對應或 socat 沒在執行時，他們還可以占用該連接埠，在你的瀏覽器重新連線時拿到金鑰。[透過 SSH 連線](../remote-connections/)時，Mac 或 Linux 主機沒有這個弱點；用桌面應用程式時，你自己的電腦也沒有。但用瀏覽器時，你用來瀏覽的電腦仍有這個弱點，因為那裡的 SSH 轉送同樣監聽 <code dir="ltr">127.0.0.1</code> 連接埠。
