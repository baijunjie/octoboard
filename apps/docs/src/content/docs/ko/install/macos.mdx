<Aside>macOS 앱은 베타 버전입니다.</Aside>

## 설치

<Steps>

1. 위 버튼으로 앱을 내려받으세요. 이름이 <code dir="ltr">.dmg</code>로 끝나는 디스크 이미지 파일을 받게 됩니다.
2. 내려받은 파일을 여세요. 열린 창에서 {productName}을(를) 응용 프로그램 폴더로 끌어다 놓으세요.
3. 응용 프로그램 폴더나 Launchpad에서 {productName}을(를) 여세요.
4. 코딩 에이전트를 하나 이상 설치한 다음(아래 참고), {productName}에서 <strong>프로젝트 추가</strong>를 눌러 프로젝트 폴더를 여세요.

</Steps>

메인 창이 열리면 끝입니다.

## 코딩 에이전트 설치

{productName}에는 AI 에이전트가 들어 있지 않습니다. 사용할 에이전트를 각각의 안내에 따라 설치하고 로그인하세요. {productName}이(가) 자동으로 찾아 줍니다. 다음 에이전트를 지원합니다.

- [Claude Code](https://code.claude.com/docs/en/setup)
- [Codex](https://github.com/openai/codex)
- [Grok Build](https://docs.x.ai/build/overview)
- [Antigravity CLI](https://antigravity.google/product/antigravity-cli)
- [GitHub Copilot CLI](https://github.com/github/copilot-cli)
- [OpenCode](https://opencode.ai)
- [Qwen Code](https://github.com/QwenLM/qwen-code)
- [Pi](https://github.com/earendil-works/pi)

## 제거

제거하기 전에 <strong>설정 › 정리 › 앱 제거 전 정리</strong>를 열고 <strong>모두 제거</strong>를 선택하세요. 켜 둔 기능이 {productName} 자체 폴더 밖에 추가한 것이 제거됩니다. 앱을 삭제할 때에는 아무것도 실행되지 않으므로, 앱을 삭제해도 이것들은 지워지지 않습니다. 그런 다음 {productName}을(를) 종료하고 응용 프로그램 폴더에서 삭제하세요.

그 뒤에 무엇이 남고 어떻게 지우는지는 [시스템은 그대로 둡니다](../../your-system/)에서 설명합니다.

## 업데이트

새 버전이 나오면 {productName}이(가) 알려 주며, 앱 안에서 바로 설치할 수 있습니다. 이 페이지로 다시 올 필요는 없습니다.

## 명령줄

터미널에서 {productName}을(를) 시작하고 종료하고, 실행 중인지 확인하고, 브라우저 접근을 켜거나 끄고, 브라우저 주소를 출력할 수 있습니다. 방법은 [명령줄](../../command-line/)에서 설명합니다.
