{productName} est un espace de développement local et open source pour les agents de code. Il réunit au même endroit vos agents et vos comptes existants : lancez des sessions côte à côte, changez de compte sans perdre la conversation, passez des tâches d’un fournisseur à l’autre, et laissez un agent coordinateur répartir le travail entre plusieurs projets.

Un agent de code est un assistant IA qui écrit et exécute du code à votre place, comme Claude Code ou Codex. {productName} n’en inclut aucun ; il fait fonctionner ceux que vous avez déjà.

## Par où commencer

- **Utiliser {productName} sur cet ordinateur :** installez l’app pour [macOS](install/macos/) ou [Windows](install/windows/). C’est tout ce dont la plupart des gens ont besoin.
- **Faire tourner des agents sur un serveur Linux ** (une machine que vous louez ou que vous laissez allumée quelque part, généralement sans écran) : [installez le programme serveur](install/linux/), puis connectez-vous-y depuis l’app de bureau, comme l’explique [Se connecter via SSH](remote-connections/).
- **Utiliser {productName} d’un ordinateur depuis un autre :** commencez par [Choisir comment se connecter](choose-how-to-connect/), qui compare les différentes voies d’accès. En bref :
  - depuis l’app de l’autre ordinateur, ou depuis un navigateur, avec la connexion SSH activée : [Se connecter via SSH](remote-connections/) ;
  - depuis un navigateur, sans activer la connexion SSH : [Navigateur via Tailscale](browser-over-tailscale/) ou [Navigateur via UU Remote](browser-over-uu-remote/).
